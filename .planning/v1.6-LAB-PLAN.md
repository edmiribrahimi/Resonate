# Laboratorio permanente — piano di esecuzione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un secondo progetto Supabase, fedele alla produzione, raggiungibile da `next dev` e da un'anteprima Vercel, seminato con cio' che le 52 prove di `49-RUNBOOK.md` pretendono.

**Architecture:** la ricetta della fase 42 (`lab-bootstrap.mjs` → `lab-fidelity.mjs` → `seed-lab-door.mjs`) rieseguita su un progetto nuovo creato dalla Management API; l'app la raggiunge in locale con `npm run dev:lab` e in rete con il ramo `lab` su Vercel, con variabili scoped a quel ramo.

**Tech Stack:** Supabase Management API (`api.supabase.com/v1`), Vercel REST API, Node 20+ (`node:crypto`), bash.

**Spec:** `.planning/v1.6-LAB-DESIGN.md`

## Global Constraints

- Nessun ref, chiave, password in nessun file tracciato: tutto in `.env.lab.local` / `.env.lab.seed.json` (`.gitignore` riga 34).
- Ogni script di laboratorio rifiuta il ref di produzione **come prima riga eseguita**.
- Nessuna modifica a `supabase/schema.sql` o a `supabase/migrations/**`.
- Nessuna scrittura in produzione: le letture di confronto usano `read_only: true`.
- Nessun dato reale nel laboratorio: indirizzi `@lab.invalid`, date calcolate da oggi.
- Il segreto di firma del laboratorio e' diverso da quello di produzione.

### Task 3: `npm run dev:lab`

**Files:**
- Create: `scripts/dev-lab.sh`
- Modify: `package.json` (scripts)

**Interfaces:**
- Produces: `npm run dev:lab`; esce `2` con `RIFIUTO` se l'URL Supabase risultante contiene il ref di produzione o se `.env.lab.local` manca.

- [ ] **Step 1: Scrivere lo script**

```bash
#!/usr/bin/env bash
# dev-lab.sh — next dev contro il LABORATORIO, mai contro la produzione.
set -euo pipefail
PRODUCTION_REF="cjsfocnhfzycbbgkwocx"
[ -f .env.lab.local ] || { echo "RIFIUTO: .env.lab.local assente — non esiste un laboratorio da cui partire." >&2; exit 2; }
set -a; source .env.local; source .env.lab.local; set +a
case "${NEXT_PUBLIC_SUPABASE_URL:-}" in
  *"$PRODUCTION_REF"*|"") echo "RIFIUTO: NEXT_PUBLIC_SUPABASE_URL e' la produzione o e' vuoto." >&2; exit 2;;
esac
echo "laboratorio: ${LAB_PROJECT_REF}  app: ${NEXT_PUBLIC_APP_URL}"
exec npx next dev "$@"
```
