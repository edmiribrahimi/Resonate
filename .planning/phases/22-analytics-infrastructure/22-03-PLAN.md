1. Create `src/lib/analytics/member-queries.ts` with member growth data function.

   `fetchMemberGrowth(supabase, granularity: 'weekly' | 'monthly')` -- Returns `{ data: GrowthDataPoint[]; summary: GrowthSummary }`.

   Where:
   ```typescript
   export interface GrowthDataPoint {
     period: string      // "2025-W03" or "2025-01" depending on granularity
     label: string       // "Jan 20" (weekly) or "Jan 2025" (monthly) for display
     referral: number    // cumulative referral members
     organic: number     // cumulative organic members
     total: number       // referral + organic
   }

   export interface GrowthSummary {
     totalMembers: number
     referralMembers: number
     organicMembers: number
     referralRate: number        // percentage
     growthThisPeriod: number    // new members in latest period
   }
   ```

   Implementation:
   - Query `profiles` selecting `created_at, referred_by` ordered by `created_at` ascending.
   - Group by week (ISO week `YYYY-Wnn`) or month (`YYYY-MM`) in JS.
   - For each period: count where `referred_by IS NOT NULL` = referral, else organic.
   - Make cumulative: each period's total = sum of all previous periods + current.
   - For weekly label: format as "MMM d" of the Monday. For monthly: "MMM yyyy".
   - Summary: total count, referral count, organic count, percentage, latest period growth.

2. Create `src/components/analytics/MemberGrowthChart.tsx` -- `'use client'` component.
   - Props: `{ data: GrowthDataPoint[] }`
   - Recharts AreaChart with ResponsiveContainer (h-56 w-full).
   - Two stacked Areas: referral (accent color, opacity 0.6) and organic (gray #666, opacity 0.3).
   - XAxis: `dataKey="label"`, muted color, small font. YAxis: muted, integer only.
   - Tooltip with dark theme styling (card bg, card-border).
   - Follow the exact pattern from RESEARCH.md MemberGrowthChart code example.
   - Empty state: "No member data yet" text if data is empty.

3. Create `src/components/analytics/GrowthSummaryCard.tsx` -- `'use client'` (uses CountUp).
   - Props: `{ summary: GrowthSummary }`
   - Gradient border card (same style as RevenueCard).
   - Primary number: totalMembers with CountUp animation.
   - Detail row: referralRate% via referral, organicRate% organic.
   - Secondary stat: growthThisPeriod new members this period.
