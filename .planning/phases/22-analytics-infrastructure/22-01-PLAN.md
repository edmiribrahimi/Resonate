  <files>package.json, package-lock.json, src/instrumentation-client.ts, src/lib/posthog/server.ts</files>
  <action>
1. Run `npm install posthog-js posthog-node recharts` to install all 3 libraries for this phase.

2. Create `src/instrumentation-client.ts` -- PostHog client-side initialization using Next.js 16 instrumentation-client convention. This file runs once on client entry, no React provider needed.
   ```
   import posthog from 'posthog-js'
   posthog.init(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
     api_host: process.env.NEXT_PUBLIC_POSTHOG_HOST!,
     defaults: '2025-11-30',
     capture_pageview: 'history_change',
     capture_pageleave: 'if_capture_pageview',
     persistence: 'localStorage+cookie',
   })
   ```
   IMPORTANT: Use `defaults: '2025-11-30'` which enables modern PostHog behaviors. Do NOT add `capture_pageview: false` or manual pageview tracking -- `'history_change'` handles SPA navigation automatically. Do NOT create a PostHogProvider or PageView component -- they are deprecated with instrumentation-client.ts approach.

3. Create `src/lib/posthog/server.ts` -- Singleton PostHog Node client for server-side event capture.
   - Use `flushAt: 1` and `flushInterval: 0` for immediate flush (critical for serverless -- events would be lost otherwise).
   - Export `getPostHogServer()` function that returns the singleton.
   - Guard with `if (!process.env.NEXT_PUBLIC_POSTHOG_KEY)` returning a no-op object to avoid crashes when env vars are missing locally.
  </action>
