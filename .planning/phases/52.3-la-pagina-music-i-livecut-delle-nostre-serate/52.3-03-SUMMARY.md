## Prova dal vivo di `soundcloud.ts`

Script scratch locale, nessuna scrittura da nessuna parte:

- `https://soundcloud.com/forss/flickermood` (traccia d'esempio della documentazione oEmbed) → `{"ok":true,"trackId":"293","soundcloudTitle":"Flickermood by Forss"}`
- permalink inesistente sullo stesso utente → log `[livecut.track_not_found_or_private] oEmbed HTTP 404`, `ok:false`
- `https://soundcloud.com/a` → `[livecut.url_not_soundcloud] link does not match the track permalink pattern`
- `http://…` (non https) → `livecut.url_not_soundcloud`; con un backslash → `livecut.url_not_soundcloud` (`control character or backslash`)
- con `fetch` simulato: HTTP 503 → `livecut.oembed_unavailable` (`oEmbed HTTP 503`); eccezione `TimeoutError` → `livecut.oembed_unavailable` (`fetch failed: TimeoutError`); 200 senza id nell'`html` → `livecut.track_id_unreadable`; 200 con la forma non codificata `api.soundcloud.com/tracks/42` e `title` non stringa → `ok:true, trackId:"42", soundcloudTitle:null`
