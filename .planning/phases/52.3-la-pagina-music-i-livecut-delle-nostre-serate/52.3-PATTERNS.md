```sql
CREATE TABLE IF NOT EXISTS public.party_credits (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
```

- `livecut_artists.artist_id` → `ON DELETE RESTRICT` come qui; `livecut_artists.livecut_id` → `CASCADE`.
- Vincoli **con nome** (`livecuts_one_per_slot`, `livecuts_published_has_cover`, `livecuts_soundcloud_url_check`) cosi' il rifiuto arriva come nome e non come `23514` anonimo (motivazione a `party_credits.sql:96-99`).

**Lettura pubblica ereditata dall'evento** (`party_credits.sql:211-228`) — da copiare per `livecuts_select_published`, aggiungendo `published_at IS NOT NULL`:
```sql
ALTER TABLE public.party_credits ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS party_credits_select_published ON public.party_credits;

CREATE POLICY party_credits_select_published ON public.party_credits
  FOR SELECT USING (
    EXISTS (
      SELECT 1
        FROM public.event_parties ep
        JOIN public.events e ON e.id = ep.event_id
       WHERE ep.id = party_id

```
Per `livecut_artists` la stessa forma con un livello in piu': `EXISTS (SELECT 1 FROM public.livecuts l JOIN public.event_parties ep ON ep.id = l.party_id JOIN public.events e ON e.id = ep.event_id WHERE l.id = livecut_id AND l.published_at IS NOT NULL AND e.is_published = true)`.

**Policy di scrittura `staff.manage`** (`20260924120000_organizers_manage_all_events.sql:39-48`):
```sql
CREATE POLICY events_update_staff ON public.events
```
