## Sampling Rate

- **After every task commit:** Run `npm run build`
- **After every plan wave:** Run the full suite command above (+ `npm run verify:persona` se si tocca `CLAUDE.md` o `.claude/rules/`)
- **Before `/gsd:verify-work`:** suite verde nei gate che non chiedono materiale; procedura di laboratorio percorsa e scritta; VERIFICATION con `file:riga` per requisito
- **Max feedback latency:** ~180 s, misurabile: e' il tempo di `npm run build`, che in questo repo e' anche il typecheck (`CLAUDE.md`, Guardrail 2). I task che non chiedono il build usano `npx tsc --noEmit` + `grep` (~30-60 s); la latenza sopra i 30 s e' strutturale, non un difetto del campionamento
