<objective>
Everything this phase built is invisible until this plan.

**The fourth role has no interface.** `MemberTable`'s role filter offers three
options, and `npm run build` reports nothing — measured: of twenty-one
role-enumeration sites, exactly **one** produces a compile error, because
seventeen sites cast `role as UserRole` and launder the new value silently. So a
staff account cannot be filtered for and the count of staff — the seat cost D-13
exists to make visible — is unreadable. That is ACCT-05's second half: a count is
not a detector of legibility.

**A refusal has nowhere to land.** `MemberTable.tsx:182-189` catches every
failure into `setError(e.message)`, and in production that message is Next's
redacted string. It is the exact defect `src/lib/capabilities/server.ts:59-63`
names, and it is where plan 43-06's `23514` would arrive today.

**The register has no reader.** D-11 exists so the history can be *read*.

Purpose: make the phase observable to the person who has to use it.
Output: one widened table, one notice per cause, one register surface, one walked
list.
</objective>
