<objective>
`ROLE-03` names four forbidden states, so the literal requirement is met without
ever probing the fourth role. That is the version of this phase in which
**`staff` acquires a capability and nothing notices**: the write matrix is the
only detector in this repository that has ever caught that class of defect, and a
role it never probes is a blind spot in the one instrument that works.

The cost is real and unwaivable. `rls-baseline-compare.mjs` treats a new persona
(`b2_persona_added`, `:705-708`) and a new cell (`b3_cell_added`, `:751`) as
**defects**, and there is no override flag for either — `--allow-lint-move`
covers B5 lints only. So the addition happens **once, in its own plan**, after
every DDL comparison of this phase and before the remaining ones, and it is
declared rather than discovered.

It also buys an assertion that is worth more than its cost. `staff` and `member`
hold the same two capabilities, so their cells must be **identical**, persona for
persona, table for table, verb for verb. That is D-02 and D-14 stated as a
measurement instead of an intention, and it would catch the one mistake the
migration could still be hiding.

Purpose: probe the role this phase created.
Output: one re-baseline, declared, with a cell-by-cell equality assertion.
</objective>
