  <name>Task 1: Create database migration for drink tables</name>
  <files>supabase/migrations/20260306000000_phase9_drinks.sql</files>
  <action>
  Create a new migration file with three tables and a PL/pgSQL function:

  **Table: drink_items**
  ```sql
  CREATE TABLE drink_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id UUID NOT NULL REFERENCES events(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    price NUMERIC(10,2) NOT NULL CHECK (price >= 0),
    sort_order INTEGER NOT NULL DEFAULT 0,
    is_available BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
  );
  ```

  **Table: drink_orders**
  ```sql
  CREATE TABLE drink_orders (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id UUID NOT NULL REFERENCES events(id) ON DELETE CASCADE,
    user_id UUID REFERENCES auth.users(id) ON DELETE SET NULL,  -- nullable for Phase 11 guest purchases
    sumup_checkout_id TEXT NOT NULL,
    total_amount NUMERIC(10,2) NOT NULL,
    status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'completed', 'failed', 'expired')),
    items JSONB NOT NULL,  -- snapshot of items ordered: [{drink_item_id, drink_name, price, quantity}]
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
  );
  ```

  **Table: drink_tokens**
  ```sql
  CREATE TABLE drink_tokens (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID NOT NULL REFERENCES drink_orders(id) ON DELETE CASCADE,
    event_id UUID NOT NULL REFERENCES events(id) ON DELETE CASCADE,
    user_id UUID REFERENCES auth.users(id) ON DELETE SET NULL,  -- nullable for Phase 11
    drink_item_id UUID REFERENCES drink_items(id) ON DELETE SET NULL,
    drink_name TEXT NOT NULL,  -- denormalized: preserves name at purchase time
    price NUMERIC(10,2) NOT NULL,
    token TEXT NOT NULL UNIQUE DEFAULT gen_random_uuid()::text,
    status TEXT NOT NULL DEFAULT 'purchased' CHECK (status IN ('purchased', 'redeemed')),
    redeemed_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
  );
  ```

  **RLS Policies:**
  - `drink_items`: SELECT for all authenticated users; INSERT/UPDATE/DELETE for users where `is_admin_or_organizer()` returns true
  - `drink_orders`: SELECT for owner (user_id = auth.uid()); all operations for service role
  - `drink_tokens`: SELECT for owner (user_id = auth.uid()); all operations for service role

  **PL/pgSQL function: fulfill_drink_order(p_order_id UUID, p_transaction_code TEXT)**
  - SECURITY DEFINER (bypass RLS)
  - Reads the drink_orders row by id
  - If status is already 'completed', return early (idempotent)
  - Loops through items JSONB array, creates drink_tokens for each unit (respecting quantity)
  - Updates drink_orders.status to 'completed' and sets updated_at
  - Returns the count of tokens created

  **Indexes:**
  - `drink_items(event_id)` for menu lookups
  - `drink_orders(sumup_checkout_id)` for webhook lookups
  - `drink_orders(event_id, user_id)` for user's orders per event
  - `drink_tokens(order_id)` for order token lookup
  - `drink_tokens(event_id, user_id)` for user's tokens per event
  - `drink_tokens(token)` unique index already from UNIQUE constraint

  Enable RLS on all three tables.
