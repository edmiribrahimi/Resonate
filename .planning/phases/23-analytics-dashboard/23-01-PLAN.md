Create `src/lib/analytics/dashboard-queries.ts`:
- Export interfaces: `RecentActivityItem` (type: "ticket"|"drink", userName: string, eventTitle: string, amount: number, createdAt: string), `KPIDashboard` (totalRevenue: number, totalMembers: number, upcomingEvents: number, recentActivity: RecentActivityItem[])
- Export `fetchKPIDashboard(supabase: SupabaseClient): Promise<KPIDashboard>` that:
  1. Uses `getServiceClient()` from `@/lib/supabase/service` to bypass RLS for cross-user aggregation
  2. Runs 4 parallel queries via Promise.all:
     - `profiles` count with `{ count: "exact", head: true }`
     - `events` count with `.gte("date", todayISO).eq("is_published", true)` and `{ count: "exact", head: true }`
     - `tickets` selecting `amount_paid` (for total ticket revenue)
     - `drink_orders` selecting `total_amount` with `.eq("status", "completed")` (for total drink revenue)
  3. Computes totalRevenue = sum of all ticket amounts + sum of all drink amounts (net -- follow same pattern as fetchEventRevenue but skip refund deduction for simplicity; this is a gross overview)
  4. Fetches recent activity: latest 10 tickets (with user full_name via join to profiles, event title via join to events) + latest 10 drink orders (same joins), combines, sorts by createdAt desc, takes top 10
  5. For recent activity joins: tickets `.select("amount_paid, created_at, profiles(full_name), events(title)")` and drink_orders `.select("total_amount, created_at, profiles(full_name), events(title)")` -- both with `.order("created_at", { ascending: false }).limit(10)`
  6. Returns KPIDashboard object
