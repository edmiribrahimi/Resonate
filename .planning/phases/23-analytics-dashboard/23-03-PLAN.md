- Import `getServiceClient` from `@/lib/supabase/service`
- ALL queries use `getServiceClient()` to bypass RLS (cross-user aggregation)

1. Export interface `MemberSpendProfile` { userId: string; fullName: string; email: string; ticketSpend: number; drinkSpend: number; totalSpend: number; eventsAttended: number; }
   Export `fetchMemberSpendProfiles(limit = 20): Promise<MemberSpendProfile[]>`:
   - Parallel fetch: profiles (id, full_name, email), tickets (user_id, amount_paid, event_id), drink_orders (user_id, total_amount, status=completed)
   - Build spendMap: Map<userId, { tickets: number, drinks: number, events: Set<eventId> }>
   - Aggregate tickets and drinks into spendMap, track unique events via Set
   - Join with profiles for name/email, sort by totalSpend desc, return top `limit`

2. Export interface `RepeatAttendeeData` { totalMembers: number; repeatMembers: number; repeatRate: number; }
   Export `fetchRepeatAttendeeRate(): Promise<RepeatAttendeeData>`:
   - Fetch all tickets (user_id, event_id)
   - Group by user_id, count distinct event_ids
   - repeatMembers = users with 2+ distinct events
   - totalMembers = total distinct user_ids with tickets
   - repeatRate = Math.round((repeatMembers / totalMembers) * 100) or 0

3. Export interface `ReferralChain` { referrerId: string; referrerName: string; referredCount: number; referredMembers: { name: string; totalSpend: number }[]; totalChainSpend: number; }
   Export `fetchReferralChains(): Promise<ReferralChain[]>`:
   - Fetch profiles (id, full_name, referred_by), tickets (user_id, amount_paid), drink_orders (user_id, total_amount, status=completed)
   - Build spend per user (tickets + drinks)
   - Group profiles by referred_by (skip nulls = organic signups)
   - For each referrer: list referred members with their spend, sum totalChainSpend
   - Sort by totalChainSpend desc, return top 20

4. Export interface `GuestConversionData` { totalConversions: number; totalGuestOrders: number; convertedSpend: number; }
   Export `fetchGuestConversion(): Promise<GuestConversionData>`:
   - Fetch drink_orders (user_id, total_amount, created_at, status=completed) where user_id is not null
   - Fetch profiles (id, created_at)
   - For each drink_order: check if profile.created_at > drink_order.created_at (order placed before registration = was a guest)
   - Count distinct user_ids as totalConversions
   - Count total orders matching criteria as totalGuestOrders
   - Sum total_amount of matching orders as convertedSpend
