  <action>
Create `src/lib/analytics/comparison-queries.ts`:
- Import fetchEventRevenue, fetchAttendanceRate, fetchDrinkSales, fetchTokenLifecycle from `@/lib/analytics/event-queries`

1. Export interface `EventComparisonData`:
   - eventId: string
   - eventTitle: string
   - revenue: number (totalNet)
   - attendance: number (checkedIn)
   - attendanceRate: number (rate %)
   - ticketsSold: number
   - drinkTokens: number
   - avgSpendPerAttendee: number (revenue / checkedIn, 0 if none)

2. Export `fetchEventComparison(supabase: SupabaseClient, eventIds: string[]): Promise<EventComparisonData[]>`:
   - For each eventId, fetch event title from events table
   - Run per-event queries in parallel: Promise.all over eventIds, each running Promise.all of [fetchEventRevenue, fetchAttendanceRate, fetchDrinkSales, fetchTokenLifecycle]
   - Map results to EventComparisonData array
   - drinkTokens = sum of all drinkSales quantities
   - avgSpendPerAttendee = revenue.totalNet / attendance.checkedIn (or 0)

3. Export `fetchAllEvents(supabase: SupabaseClient): Promise<{ id: string; title: string; date: string }[]>`:
   - Simple query: events (id, title, date) ordered by date desc
   - Used for the event selector dropdown

Create `src/components/analytics/EventSelector.tsx`:
- "use client" component
- Accept props: `{ events: { id: string; title: string; date: string }[]; selectedIds: string[]; maxSelection?: number }` where maxSelection defaults to 4
- Render a list of events with checkboxes
- When selection changes, navigate via URL search params: `?events=id1,id2,id3` (use `useRouter().push()`)
- Disable unchecked checkboxes when maxSelection reached
- Show selected count: "N/4 selected"
- Styling: card wrapper, each event row as flex with checkbox, title, date badge
- Date formatted as short date (e.g., "Mar 9, 2026")

Create `src/components/analytics/EventComparisonChart.tsx`:
- "use client" component
- Accept props: `{ data: EventComparisonData[]; mode: "absolute" | "per-attendee" }`
- Build chart data based on mode:
  - Absolute: metrics = ["Revenue", "Tickets Sold", "Drink Tokens", "Attendance"]
  - Per-attendee: metrics = ["Revenue/Attendee", "Drinks/Attendee", "Attendance Rate %"]
  - Each metric row: { metric: "Revenue", [event1.title]: value1, [event2.title]: value2, ... }
- Render Recharts BarChart with grouped bars:
  - XAxis: metric names (dataKey="metric")
  - YAxis: numeric values
  - One `<Bar>` per event with EVENT_COLORS palette: ["var(--color-accent)", "#6366f1", "#10b981", "#f59e0b"]
  - `radius={[4, 4, 0, 0]}` on each Bar
  - Legend component to show event names
- Dark tooltip with project card styling
- ResponsiveContainer height 300
- Empty state: "Select 2+ events to compare"
