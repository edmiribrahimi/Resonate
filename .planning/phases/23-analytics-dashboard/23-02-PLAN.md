Extend `src/lib/analytics/event-queries.ts` with 2 new functions and types (append after existing code, do NOT modify existing functions):

1. Export interface `MarketInsights`:
   - avgSpendPerAttendee: number (total revenue / checked-in count)
   - peakPurchaseHours: { hour: number; count: number }[] (top 5 hours by combined ticket+drink purchase count)

2. Export `fetchMarketInsights(supabase: SupabaseClient, eventId: string): Promise<MarketInsights>`:
   - Parallel fetch: tickets (amount_paid, created_at), drink_orders (total_amount, created_at, status=completed), attendance count (checked_in=true, head: true)
   - avgSpendPerAttendee = (sum ticket amounts + sum drink amounts) / checkedIn count (0 if no attendees)
   - peakPurchaseHours: combine ticket and drink order created_at timestamps, extract hour (0-23) via `new Date(ts).getHours()`, count occurrences, sort desc, take top 5

3. Export interface `FunnelStep`: { name: string; value: number; fill: string }

4. Export `fetchPurchaseFunnel(supabase: SupabaseClient, eventId: string): Promise<FunnelStep[]>`:
   - Per research recommendation: compute funnel from Supabase only (no PostHog)
   - Steps (each a separate count query via head: true or .length):
     a. "Checkouts" = count of all drink_orders for event (any status -- users who initiated checkout)
     b. "Payments" = count of drink_orders with status='completed'
     c. "Tokens" = count of drink_tokens for event
     d. "Redeemed" = count of drink_tokens with status='redeemed'
   - Return array of FunnelStep with decreasing values, using color palette: ["var(--color-accent)", "#6366f1", "#8b5cf6", "#c084fc"]
