**Shared SalesDashboard component** -- create `src/components/events/SalesDashboard.tsx`:

A presentational component (can be server or client -- server preferred for simplicity since it only displays data, no interactivity needed). Receives props:

```typescript
interface TierSalesData {
  id: string;
  name: string;
  price: number;
  quantity: number;
  sold: number;
  revenue: number;
}

interface BuyerData {
  id: string;
  memberName: string;
  memberEmail: string;
  tierName: string;
  purchaseDate: string;
}

interface SalesDashboardProps {
  eventTitle: string;
  tiers: TierSalesData[];
  buyers: BuyerData[];
  totalRevenue: number;
  totalSold: number;
}
```

Layout (per user decisions):

1. **Revenue summary** at the top:
   - Total revenue prominently displayed (e.g., "EUR 1,234.50" in large accent text)
   - Total tickets sold (e.g., "42 tickets sold")

2. **Per-tier breakdown** section:
   - Heading: "Tier Breakdown"
   - Each tier as a card or row showing: tier name, price (EUR), sold/available count (e.g., "15/50 sold"), tier revenue (e.g., "EUR 225.00")
   - Visual progress bar or percentage for each tier's sell-through rate
   - Sold-out tiers highlighted

3. **Buyer list** section:
   - Heading: "Buyers"
   - Per user decision: "member name, tier purchased, purchase date, and member email"
   - Responsive: on mobile, stack as cards. On larger screens, a simple table.
   - Sorted by purchase date descending (most recent first)
   - Empty state: "No tickets sold yet"

Style: consistent with existing Resonate dark theme. Cards with rounded-2xl, border-card-border, bg-card. Accent color for revenue numbers.

**Organizer sales page** -- create `src/app/(organizer)/organizer/events/[id]/sales/page.tsx`:

Server component at `/organizer/events/[id]/sales`. Follow the established organizer page pattern:

1. Read role/status/userId from middleware headers. Redirect if not organizer/master.
2. Verify event ownership (organizer owns event OR user is master).
3. Fetch event: `supabase.from("events").select("id, title").eq("id", eventId).single()`
4. Fetch tiers with sold counts:
   - Get tiers: `supabase.from("ticket_tiers").select("id, name, price, quantity").eq("event_id", eventId).order("created_at")`
   - For each tier, get ticket count: `supabase.from("tickets").select("*", { count: "exact", head: true }).eq("tier_id", tier.id)`
   - Compute: sold = count, revenue = count * price
5. Fetch buyers: `supabase.from("tickets").select("id, amount_paid, created_at, tier_id, user_id, profiles!user_id(full_name, email), ticket_tiers!tier_id(name)").eq("event_id", eventId).order("created_at", { ascending: false })`
   - Map to BuyerData format, extracting profile name/email and tier name from joins
6. Compute totalRevenue = sum of all tier revenues, totalSold = sum of all tier sold counts
7. Render: header with back link to `/organizer/events`, "Sales" title with event title subtitle
8. Render `<SalesDashboard>` with computed props
9. Include MobileNav
