  - Props interface: `{ preview: string; children: React.ReactNode }`

  - Export `EmailLayout` as a named export and also export the `BRAND` constants object for use in child templates.

  **Step 3: Create the email sending utility**
  Create `src/lib/email.ts`:

  - Import `Resend` from "resend"
  - Create the Resend client instance: `const resend = new Resend(process.env.RESEND_API_KEY)`
  - Define the from address: `const FROM_ADDRESS = process.env.RESEND_FROM_EMAIL || "Resonate <onboarding@resend.dev>"`
  - Export an async `sendEmail` function with typed params: `{ to: string; subject: string; html: string }`
  - Implementation: call `resend.emails.send({ from: FROM_ADDRESS, to: [to], subject, html })`
  - On error: `console.error("Email send failed:", error)` and throw the error
  - On success: return the data object
  - **Important:** This utility is intentionally simple. The calling code decides whether to fire-and-forget (`.catch(console.error)`) or await the result.
