### `supabase/migrations/20261013150000_mixed_tiers_entry_until.sql` (migration)

**Analogo:** `supabase/migrations/20261013120000_external_tickets.sql` (stesso rilascio) + regola «drop senza IF EXISTS» del benefit.

**Testata e convenzioni** (external_tickets, righe 1-24): commento italiano che dice cosa, perche', RLS invariata, e la riga finale `-- Nessun BEGIN/COMMIT: la Management API avvolge gia' la migration.`

**Colonna + COMMENT** (external_tickets, righe 60-66):
```sql
ALTER TABLE public.ticket_tiers
  ADD COLUMN IF NOT EXISTS sold_out boolean NOT NULL DEFAULT false;

COMMENT ON COLUMN public.ticket_tiers.sold_out IS
  'Esaurito A MANO da chi organizza. Vince su quantita'', date e conteggi, in UI e in '
  'buildOrderQuote. ...';
```
→ `ADD COLUMN IF NOT EXISTS entry_until time` (nullable), COMMENT: ora di Torino; < 12 = mattina dopo la data della serata (`nightBoundaryInstant`); NULL = nessun limite.

**CHECK da rifare:** l'insieme attuale delle cause (`20260805120000_door_scan_events.sql:90-99`) va ricopiato **per intero** piu' i due valori nuovi:
```sql
CHECK (cause IN (
  'double_read', 'second_ticket_same_holder', 'two_devices', 'invalid_signature',
  'not_in_cache', 'wrong_night', 'refunded_before_night', 'refunded_after_night'
))
```
Il commento della migration originale (`:54-58`) dichiara lo specchio con `DoorScanCause` in `outcome.ts`: **stesso commit** per le due parti.

**`access_type`:** il CHECK originale e' `CHECK (access_type IN ('free_public', 'free_rsvp', 'paid'))` inline (`20260225150000_party_architecture.sql:18`). Ordine: `UPDATE ... SET access_type='paid' WHERE access_type='free_rsvp'` **prima** del nuovo CHECK.

**Applicazione al lab** (`scripts/lab-apply-migration.mjs:6-8`):

### `src/lib/door/entry-until.ts` (nuovo, predicato unico)

```ts
  if (!doorRefusesRefunds()) return false;
  if (args.refundedAt === null) return false;

  if (!(args.refundedAt < args.nightStart)) return false;
```

**Fonte:** `checkin/route.ts:1009-1037`, `attendance/route.ts:888-915`.
**Vale per:** `entry_until` online e nel manifesto. Errore → log con categoria propria, valore `null`, **ammettere**.

**Vale per:** l'istante dell'ora limite si calcola sul server (`entryUntilInstant`) e viaggia come ISO; il telefono confronta istanti, mai orari di Torino.
