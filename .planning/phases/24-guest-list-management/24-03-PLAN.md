**1. Create src/app/(organizer)/organizer/events/[id]/guest-list/csv-actions.ts:**

"use server" at top. Server actions (all verify organizer/master role + event ownership):

**bulkAddGuests(eventId: string, guests: { first_name: string, last_name: string, email?: string, party_id?: string }[]):**
- Validate each guest (name required, email format if provided)
- Normalize emails to lowercase
- Batch INSERT into `guest_list_entries` using `ON CONFLICT (event_id, LOWER(email)) DO NOTHING` for deduplication
- For guests with email: process sequentially with 500ms delay between each to respect rate limits (both Supabase auth and Resend)
- Use `processGuestEntry` from `@/lib/guest-list/process-entry` for each
- Track results: { imported: number, skipped: number, failed: number, errors: string[] }
- Revalidate path
- Return results summary

**cloneGuestList(sourceEventId: string, targetEventId: string, targetPartyId?: string):**
- Verify organizer has access to both events
- Fetch all guest_list_entries from source event (name + email only, ignore status/profile/ticket)
- Insert into target event as new entries with `status='pending'`, `party_id=targetPartyId || null`
- Use `ON CONFLICT` to skip existing emails at target event
- Do NOT auto-process cloned entries (organizer can trigger processing manually or entries will be processed when they click "Process" or add individually)
- Return `{ cloned: number, skipped: number }`

**Changes to the existing route:**

Inside the `parties.map(async (party) => { ... })` block, after fetching attendees from tickets:

1. **Fetch guest list entries for this party:**
   ```typescript
   // Guest list entries without tickets (name-only check-in)
   const { data: guestListEntries } = await serviceClient
     .from("guest_list_entries")
     .select("id, first_name, last_name, status, email")
     .eq("event_id", party.event_id)
     .or(`party_id.eq.${party.id},party_id.is.null`)
     .is("ticket_id", null)
     .not("status", "eq", "failed");
   ```

2. **Map guest list entries into attendee format:**
   ```typescript
   const guestListAttendees = (guestListEntries ?? []).map((g) => ({
     ticketId: null, // No ticket -- this is a guest list entry
     guestListEntryId: g.id,
     name: `${g.first_name} ${g.last_name}`,
     checkedIn: g.status === 'checked_in',
     checkedInAt: null,
     isGuestList: true, // Flag to distinguish in UI
     hasEmail: !!g.email,
   }));
   ```

3. **Merge with ticket-based attendees:**
   - Combine `filteredAttendees` with `guestListAttendees`
   - Apply the same search filter to guest list entries
   - Sort: checked-in first (for both types), then alphabetical

4. **Update the response shape:**
   - `totalTickets` stays as is (only counts actual tickets)
   - Add `guestListCount: guestListAttendees.length` to the response
   - `attendees` array now includes both ticket holders and guest list entries
   - Each attendee has `isGuestList: boolean` flag

5. **Add a POST handler for guest-list check-in:**
