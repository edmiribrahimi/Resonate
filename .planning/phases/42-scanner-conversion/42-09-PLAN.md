<objective>
Rename the door's surfaces, lines and ink from the aliases phase 40 left behind
to the names the product actually uses.

Purpose: `ScannerClient.tsx` carries **42 legacy token utilities** across four
alias names, and check B counts exactly those four on any declared surface. Each
alias resolves, in the token layer, to the current name at the identical value —
which is why this is the least interesting part of the conversion and the easiest
to leave half finished. A leftover here is not a wrong colour; it is a surface
declared converted while still speaking the previous vocabulary, and check B is
the only thing that will ever notice.

It gets its own plan for one reason: it is a different kind of edit from the
palette work, done in a different pass, and mixing the two inside a 3449-line
file is how a rename becomes a redesign.

Output: four alias names gone from the door, at the same rendered values, with
the count reconciled by the gate's own matcher.
</objective>
