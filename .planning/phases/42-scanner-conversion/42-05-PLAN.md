<objective>
Build the four derogations this phase needs **before** the run that would need
them, so that none of them is a concession made to clear a red.

Purpose: D-41-16 is the rule and it was paid for — *an exemption discovered on a
red run is an exemption nobody trusts*. When the fence comes down, five checks go
red at once on code that is correct for reasons already argued: check A on the
door's accept and refuse vocabulary, which stays raw because the semantic set has
no green and phase 40 declined to invent one; check D on two door pages that
cannot import the shell without wrapping a full-screen safety surface in outer
padding; `verify:dialogs` on a status layer the gate's own fence entry already
describes as *not a dialog*; and check E in a direction nobody counted, where
deleting a wrapper makes the door look, to the gate, like a surface that must
reserve a 224px column — the exact opposite of what the door wants.

Two of the four can be built now, and are built here **empty**: a mechanism with
no entries forgives nothing, and this repository has the precedent — check D's
typographic measures shipped with zero entries, before the red run that would
have made them look like a concession.

Two cannot be built now, and the reason is mechanical rather than cautious: the
check E constants must point at files that exist in the state the commit
creates, and the dialog exemption would overlap a fence that is still standing.
Those two are written **verbatim** here, proved on a throwaway branch, and
transcribed later.

Output: two empty mechanisms that refuse when stale, two edits written out word
for word, and a suite as green as it was.
</objective>
