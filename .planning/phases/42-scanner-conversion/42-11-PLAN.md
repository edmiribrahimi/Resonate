<objective>
Take down the fence, declare the door, and switch on the gate that measures it —
all of it in the order that never leaves a gate red for a reason that is not a
defect.

Purpose: this is the plan that makes the phase's work **measurable by the rest of
the repository**. Until now the door has been fenced: three gates skip it by path,
so every conversion of the last five plans has been asserted by build and by
grep, never by the instrument. Opening the fence turns the door into a declared
surface, and five checks start looking at it at once.

**Every derogation those five checks will need already exists, written before this
run.** Check A's per-utility list and check D's full-bleed declaration were built
empty in plan 42-05; the dialog exemption and the check E pairing were written
verbatim there and proved on a throwaway branch; the mapping decided every target
and every exception in plan 42-04. Nothing here is discovered. This plan
transcribes and then runs.

**One plan owns every gate edit**, and that is the rule this repository already
paid for: a shared list is one file every plan in a wave would want to edit, so
several plans report and one plan writes.

**And the ordering rule that gives this plan its shape:** *a gate is registered
when the code that makes it green exists, never before.* Registering the
legibility gate in wave 0 would have measured the old colours and stayed red for
the whole interval the door pass blocked — and a gate that is red because it is
waiting is indistinguishable from a gate that is red because something is broken.
Both get ignored.

Output: no fence, two declared surfaces, seventeen gates plus one, and every
exception a sentence somebody signed.
</objective>
