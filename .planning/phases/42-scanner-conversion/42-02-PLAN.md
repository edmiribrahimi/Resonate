<objective>
Make the word *unchanged* mean something on a file nobody can hold in their head,
and write down the part of this phase that no command will ever close.

Purpose: criterion 3 says *every scanner behaviour is unchanged from before the
conversion*. `ScannerClient.tsx` is **3449 lines** and owns the offline queue,
the torch, auto-return, the three outcomes and undo. After a conversion touching
99 class-string sites, *unchanged* asserted from memory is not an assertion — it
is a hope. A mechanical record taken **before** turns it into a diff.

The record is worth exactly what it covers, and its limits matter as much as its
contents. It proves that the **constants** and the **shapes** did not move. It
does not prove that a phone vibrated, that a queue survived a restart, that the
torch lit, or that a screen was readable at arm's length in a dark room — those
live outside this repository, in a camera, a haptic motor, an IndexedDB store and
a person's eye. `42-VALIDATION.md` counts **ten** such rows and this plan writes
the procedure for each, with every result at `pending` until somebody looks.

Both halves are due **now**, before the block: the record has to describe the
code the first real door will run on, so it cannot wait for the door pass it
exists to accompany.

Output: a re-runnable capture script, the pre-conversion record with its SHA and
date, and the ten procedures.
</objective>

<phase_rules>
1. **There is no test runner.** Never write that something is verified because
   tests pass. The proofs are a gate's exit code, a grep with an expected count,
   a source assertion, `npm run build` (which **is** the typecheck), and a
   written human procedure whose result is `pending` until a person looks.
2. **⚠ `scripts/verify-conversion.mjs` holds NUL bytes** and the default `grep`
   here skips it silently. Use `LC_ALL=C /usr/bin/grep` or the Read tool.
3. **`.planning/` is tracked on a PUBLIC repository.** Roles, never people. No
   date of an unannounced night, no venue, no sigla, no line-up. Anchor to
   **events**, never to dates.
4. **DEF-41-01 — never spell a bracketed arbitrary-value utility in prose.**
5. **macOS/BSD.** `grep -E`, `sed -i ''`.
6. **No package is installed by this phase.**
7. **No behaviour change, and in this plan no source change at all.** This plan
   reads `src/` and writes only a script and two documents.
8. **An exemption discovered on a red run is an exemption nobody trusts.**
</phase_rules>
