<objective>
Delete a wrapper whose only reason to exist has been superseded, without letting
the door acquire the layout that wrapper was built to keep off it.

Purpose: `src/components/layout/MobileNav.tsx` has **one consumer left in the
whole tree** — the door — after the previous conversion phase moved the other ten
surfaces to the responsive form. It exists only because it predates the
navigation primitive's `form` prop; passing that prop does the identical thing
with one layer fewer.

**The door does not take the 224px column.** That is the reason the wrapper was
created and it is still true: this screen is read at an entrance, one-handed, in
the dark, with a queue in front of it.

The part that makes this a plan rather than a two-line edit was measured by
running the gate: the moment the door imports the primitive directly, check E
classifies it as mounting the **responsive** form and demands the column — the
exact opposite of the intent — and the minimum fix is **two** edits, not one.
With only the first, the gate exits 2, because the two halves of one gate would
be reading different trees. Both were proved on a throwaway branch in plan 42-05
and are written out verbatim there; this plan transcribes them.

And the deletion leaves **eighteen sentences** across the tree naming a file that
no longer exists, twelve of them on surfaces already declared converted. No gate
reads them — the gates run with comments stripped — which is precisely why the
third road, leaving them silent, is the road that produced the defect this phase
was called to close.

Output: one fewer component, one gate still measuring the same thing, and no
sentence naming a ghost.
</objective>
