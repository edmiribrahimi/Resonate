<objective>
Make the instrument measure again, and give the six pages it will then complain
about a disposition that does not lie about who owns them.

Purpose: `npm run verify:conversion` **exits 2 today with "Nothing was
measured"** — `checkManifest()` refuses on four `CONVERTED` entries naming
Finance/Analytics pages that are no longer on disk (DEF-45-01, D-42-06). The same
list is read by `verify:touch-targets`. Two of the seventeen gates in this
repository currently measure nothing, and one of them is **the gate this phase
must close its own criteria with**. A refusal is not a failure: it means the
measurement did not happen, and a phase cannot prove a conversion with an
instrument that is not running.

Repairing DEF-45-01 is necessary and **not sufficient**, and this was measured
rather than assumed: with the four entries gone, checks A–E pass and **check F
fails on six pages** that phases 44 and 45 added and never declared
(`42-RESEARCH.md` §2.7, DISCORDANZA 3, gate executed on a copy of the tree).
Those six are not this phase's to convert and not this phase's to declare
converted — declaring them would be exactly the lie
`conversion-manifest.mjs:479-480` names, *"a list of claims is how a gate becomes
a rubber stamp"*. They get the third thing the gate itself offers: a fence, by
name, with the owning phase written inside it.

Output: a `verify:conversion` that reaches a verdict and is green, a second fence
that dissolves loudly, and a deferred item that says whose debt the six pages
are.
</objective>

<phase_rules>
Standing rules for every plan in phase 42. Repeated in each plan rather than kept
in a preamble, because a preamble is a place nobody reads.

1. **There is no test runner.** `package.json` has no `test` script and the tree
   has no `*.test.*` or `*.spec.*`. Never write that something is verified
   because tests pass. The proofs available are a gate command with its exit
   code, a grep with an expected count, a source assertion, `npm run build`
   (which **is** the typecheck), and a written human procedure whose result is
   `pending` until a person looks.
2. **⚠ `scripts/verify-conversion.mjs` is invisible to the shell's default
   `grep`.** It holds two literal NUL bytes and the default `grep` here is
   `ugrep -I`, which skips binary files **silently**. Use
   `LC_ALL=C /usr/bin/grep` or the Read tool. **A zero-hit grep there is not
   evidence of absence.**
3. **`.planning/` is tracked on a PUBLIC repository.** Roles, never people. No
   date of an unannounced night, no venue, no sigla, no line-up. Everything is
   anchored to **events**: *the first real door*, *the door pass on the
   unconverted scanner*, *a day without a night*.
4. **DEF-41-01 — never spell a bracketed arbitrary-value utility in prose.**
   Tailwind's source detection scans `.planning/`, and a planning document that
   quoted one compiled a dead rule into the shipped stylesheet. Refer to such a
   site by `file:line`; do not retype the utility.
5. **macOS/BSD.** `grep -E` for extended regex, `sed -i ''` for in-place.
6. **No package is installed by this phase.** `42-RESEARCH.md` §10 states none is
   needed, including for the colour mathematics. Needing one is a HALT and an
   owner decision.
7. **No behaviour change.** No outcome, no dwell, no haptic, no queue, no undo,
   no torch, no auto-return, no `qrbox`, no `fps`, no `facingMode`. No
   restructuring of `ScannerClient.tsx`.
8. **An exemption discovered on a red run is an exemption nobody trusts**
   (D-41-16). Every derogation this phase introduces is written before the run
   that would need it.

**Quick run for this phase:**
`npm run verify:conversion && npm run verify:dialogs && npm run verify:touch-targets && npm run build`
</phase_rules>
