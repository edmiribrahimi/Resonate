A `"use client"` component for tag-style input (per locked decision: type artist name, press enter to add as chip/tag, click to remove).

Behavior:

- Press Enter or comma to add tag (prevent form submission on Enter)

- Backspace on empty input removes last tag

**2. Create `src/components/events/EventForm.tsx`:**
A `"use client"` component used for both create and edit.

Props interface:
```
interface EventFormProps {
  initialData?: {
    id: string;
    title: string;
    description: string;
    date: string;
    time: string;
    location: string | null;
    location_secret: boolean;
    lineup: string[];
    cover_image: string | null;
    capacity: number | null;
    is_published: boolean;
  };
  action: (formData: FormData) => Promise<{ success: boolean; id?: string; error?: string }>;
  submitLabel: string;
}
```

Form fields (Claude's discretion on layout order, use sensible grouping):
- **Title**: text input, required, placeholder "Event title"
- **Description**: textarea, required, placeholder "Describe the event..."
- **Date**: native `<input type="date">`, required
- **Time**: native `<input type="time">`, required
- **Location**: text input, optional, placeholder "Venue address"
- **Secret Location**: toggle/checkbox. When checked, show explanatory text "Location will be hidden until members purchase a ticket". Style as a toggle row with label on left and switch on right.
- **Lineup**: TagInput component. Label "Lineup" with helper text "Press Enter to add artist"
- **Cover Image**: File input with preview. Implementation:
  - Accept `image/jpeg,image/png,image/webp` only
  - Max 5MB client-side check (show error if exceeded)
  - When file selected, show preview thumbnail
  - On form submit, upload to Supabase Storage `event-images` bucket using browser client (`createClient` from `@/lib/supabase/client`): path `covers/{timestamp}-{sanitized-filename}`
  - Get public URL via `getPublicUrl()` and include in FormData as `cover_image` string
  - If editing and initialData has cover_image, show existing image as preview with option to change
- **Capacity**: number input, optional, placeholder "Leave empty for unlimited", min 1

Form submission:
- Collect all fields into FormData (lineup as JSON string, cover_image as URL string after upload)
- Show loading state during upload and submission
- Call the `action` prop with FormData
- On success: redirect to `/organizer/events` (use `useRouter` from next/navigation)
- On error: display error message at top of form

Styling: consistent with existing codebase -- use `rounded-xl border border-card-border bg-card` for form sections, `bg-background text-foreground` for inputs, `bg-accent text-white rounded-full` for submit button. Mobile-first layout.
