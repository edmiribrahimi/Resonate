<objective>
Close CAP-06: review every one of the 26 policies that re-evaluate the current user
once per row, record the result per policy, and wrap the calls that are still there.

Purpose: the advisor names all 26 and none is wrapped. The transformation itself is
unconditionally safe — `auth.uid()` takes no arguments, so the wrapped expression
cannot depend on row data — and the danger is entirely in the larger rewrite it
tempts. Two policies contain a genuinely **correlated** `EXISTS` that must be left
alone, and one is the privilege-escalation guard.

Output: a 26-row review document, one applied migration, and the three pieces of
evidence CAP-06 asks for that no diff can supply.
</objective>

  Proved on this database with `EXPLAIN (VERBOSE, COSTS OFF)`: both `auth.uid()` and
