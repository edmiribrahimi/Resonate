<objective>
The two halves of this phase that break **without anything breaking**.

DS-02 is the easiest thing here to lose silently: when a semantic drifts into a
brand colour the screen still renders, and a state just starts looking like a
format. DS-03 is the same shape one step further — a gradient that is SunSet's
exclusive signature has no technical objection to appearing anywhere.
`40-UI-SPEC.md` §3.4 argued that the `--sem-*` prefix *"is what lets a script hold
it"* and then commissioned no script; this plan is that script, and its sibling.

Purpose: give DS-02 and DS-03 the only enforcement they will have. `npm run build`
cannot see either.
Output: `scripts/verify-semantic-separation.mjs` and
`scripts/verify-sunset-gradient.mjs`, wired, green, and each proven able to go red.

**The failure mode both scripts are written against.** A check that goes red on a
correct file gets declared noisy and switched off, after which it guards nothing —
the defect `verify-media-strip.mjs:51-62` was written to prevent. Three things are
correct today and must stay green: the six brand hexes in `ColorSwatchPicker.tsx`
(format identification colours are **data on a row**), the `#0A0712` in
`layout.tsx` (the browser chrome is painted **before any stylesheet loads**), and
every two-stop accent fade (`bg-gradient-to-br from-accent/30 to-accent/5` — those
follow `--accent` and are correct).
</objective>

The five checks:

  **A. Semantics are declared literally, on both sides.** In the token file, every
  `--sem-*` declaration's value must be a literal — a `#`-hex or an `rgba(` — and
  must not contain `var(`. Symmetrically, no non-`--sem-*` token's value may
  contain `var(--sem-`. `40-UI-SPEC.md` §3.4 device 2, and the reason is measured:
  **two of the four semantics coincide in value with something else in the system**
  (`--sem-warn` `#FFB25E` is `--amber` is SunSet's identification colour;
  `--sem-info` `#A493C0` is `--muted`), so there is no chromatic separation to lean
  on — only a structural one, and a single `var()` across the boundary dissolves it.

  **B. One home for a brand hex.** Read every hex value declared in the token file's
  `:root`. No file under `src/`, other than the two exemptions, may contain any of
  them. Strip comment lines before counting. Report `path:line: text`.

  **C. A semantic never identifies a format.** No **line** under `src/` may carry
  both a `sem-`-prefixed colour utility (matched at a boundary, so `bg-sem-crit` and
  `bg-sem-crit/20` match and nothing else does) and a format identifier — the
  string `color_hex`, or a CamelCase format name literal `SunSet`, `RamaDub`,
  `MotionLab`. Zero hits today. This is the first direction of DS-02 and it is
  deliberately line-scoped rather than file-scoped: Phases 44 and 45 will build
  surfaces that legitimately show both a format and a stage badge in the same file,
  and a gate that goes red on those is a gate that gets removed.

  **D. The palette has one editable source.** For each of the five sunset keys in
  `ColorSwatchPicker.tsx`'s `CATALOGUE_COLORS` — amber, orange, pink, pinkSoft,
  violet — the hex must equal the corresponding token value declared in the token
  file, compared case-insensitively. The sixth, `neutral` `#8C82A6`, is **exempt
  with its reason in the header**: it is the catalogue's deliberate neutral, chosen
  on its own merits, and it is the same value as `--soy`, which D-40-06 keeps out
  of the token set until somebody says what it is for. The two must not be merged
  before that answer arrives. `40-UI-SPEC.md` §3.2: *two hand-maintained copies of a
  palette is how a palette acquires a seventh colour nobody decided* — the contract
  is that a divergence **fails** rather than being noticed later on a screen.

  **E. No format becomes a token.** The token file declares no token whose name
  matches a format name or sigla — `sunset`, `ramadub`, `motionlab`, `resonate`,
  `snst`, `rmdb`, `mtnlb`, `rsnt` — and exposes no such utility through
  `@theme inline`. `--grad-sunset` is not a format token: it names a gradient, it
  carries no `--color-*` mapping, and check E must be written so it stays green,
  with the distinction stated in the header.

Preflight `refuse()` (exit 2): `src/` missing, the token file missing, either
exemption path missing, the walk empty, **or the token file declaring zero
`--sem-*` tokens** — this script must never report a green about a semantic set
that does not exist.

**WHAT A GREEN DOES NOT MEAN**, in RESEARCH §7's words: a `grep` reads
**declarations, not intent**. It cannot see a semantic expressed as a raw hex it
does not know about, nor a format colour reached through a variable renamed on the
way, nor a class name built by string concatenation. And it says nothing about
whether a colour is **right** — an amber mark still cannot tell a reader *caution*
from *this is a SunSet night* by hue alone (Open Question 3), which is why anything
amber carries text. Those stay human.

Secrecy paragraph: reads only committed files, prints paths, line numbers and
source lines, no network, no environment variable, no artefact. No format's sound
is described anywhere in this file — three of the four formats have no written
manifesto and a script comment is not where one gets written
