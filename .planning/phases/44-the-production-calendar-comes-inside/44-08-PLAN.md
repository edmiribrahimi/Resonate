  <action>
    Create `scripts/verify-ics-import.mjs`.

    **Header**, in `verify-tokens.mjs`'s shape: *what it asserts, in one sentence*; *why a
    structural check and not a test on one file* — there is no test runner in this
    repository and the build cannot see this failure; then the lettered check list; then
    **WHAT A GREEN DOES NOT MEAN**, which for this check reads: it says the parser agrees
    with the file the owner supplied **on 2026-08-15**, and nothing more. It does not say the
    anchors are the right anchors, it does not say a proposal reads as unsettled, and every
    count in it is an assertion about **that file** — a new file re-opens the whole list,
    which is why the check exists rather than a comment.

    **It reads the module, it does not re-implement it.** Import `parseIcs`, the classifier,
    the anchor resolver and `reconcile` from `src/lib/production/ics/`. A check that
    re-implements the thing it checks agrees with itself.

    **The checks, lettered, each printing a `✓` or a `✗` with counts only:**

    A. **Container.** 92 `VEVENT`s; 92 distinct `UID`s; 3 folded lines actually unfolded
       (via `countFoldedLines`, so the assertion is that unfolding HAPPENED and not that it
       compiled); 0 `VALUE=DATE`; exactly 1 event-level `RRULE`; 0 `RECURRENCE-ID`, `EXDATE`
       or `RDATE`; the file splits on LF. Report the `VTIMEZONE` and `VALARM` counts too, and
       assert that no `VTIMEZONE` `DTSTART` reached an event — the warning sign is 96
       `DTSTART`s for 92 events.

    B. **Classification.** class A (canonical piece) 56; class B (legacy inverted) 3; class C
       (night) 14; class D 19; the kind vocabulary is **exactly the six** and no seventh
       appears; **zero `Podcast`**. If the legacy count is 0, fail with the reason written
       out: a two-grammar parser drops three real pieces, two of which are the file's only
       genuine anchor overrides.

    C. **The join, with its negative control.** Zero nights match by sigla alone — this is
       the control that proves the alias path is doing work rather than the join accidentally
       succeeding. And **zero pieces are dated after the night they announce**, which is the
       warning sign for the format-plus-number join that ignores the venue word.

    D. **Anchors.** timetable 7 of 7 on the night itself; the night's LiveCut 6 of 6 inside
       the next night's ISO week; after movie 6 of 7 at the next listing minus one, with the
       seventh identified as a legacy-form override rather than a failure; satellite Tonight
       2 of 2 same-day; satellite Recap and LiveCut 2 of 2 on the following Monday; SunSet
       LiveCut 6 of 6 on the Monday and Tuesday following; and **both the night's and
       SunSet's listings reported `not_derivable` and never proposed**.

    E. **Idempotence.** Run `reconcile` twice over the same parsed input against the plan the
       first pass produces. **The second pass returns an empty plan** — no insert, no update,
       no divergence. This is criterion 5's only automated evidence.

    F. **Confidentiality, and it checks this script's own output.** Capture everything the
       run printed and assert that it contains no `SUMMARY` value from the file, no
       four-digit-year date, and no venue word — implemented by taking each parsed `SUMMARY`,
       stripping the public tokens (the six kind words, the five published sigle, the four
       format names), and asserting that no remaining token of three or more characters
       occurs anywhere in the captured output. A check whose own output leaks the material
       is worse than no check.

    G. **The SQL mirror.** Read `src/lib/production/ics/vocabulary.ts` and the two migration
       files, and assert that every member of `PIECE_KINDS`, `PIECE_DATE_ORIGINS`,
       `UNRESOLVED_REASONS`, `VENUE_STAGES`, `ANCHOR_KINDS` and `ANCHOR_DIRECTIONS` appears
       inside a `CHECK` constraint, and that no `CHECK` vocabulary contains a member the
       TypeScript does not. `src/lib/door/outcome.ts` declares this cross-check as a rule;
       here it becomes a check.

    H. **The import cannot reach the night table.** Assert that `event_parties` occurs zero
       times in `src/lib/production/ics/` outside a comment, and that no file under
       `src/lib/production/` carries the `"use server"` directive (D-44-26).

    **Grep hygiene:** where a check counts a token in a source file, strip comment lines
    first — a header that names the forbidden token would otherwise make the check
    self-invalidating. This repository has already recorded that failure shape.

    **Skipping.** When no `docs/*.ics` is present, print the sentence saying why —
    *the material is gitignored and lives only on the owner's machine; nothing was
    measured* — and **exit 2**, the refusal code. Never exit 0, because a green that
    silently skipped is worse than no check, and never exit 1, because a refusal is not a
    failure. Checks G and H do not need the material and run regardless; say which checks
    ran and which were refused.

    **Verdict block**, in `verify-media-strip.mjs`'s form: `ICS_IMPORT_OK` on success with
    the sentence *read the header before treating this as safety*, or
    `ICS_IMPORT_FAIL — N check(s) failed: …` and exit 1.

  <action>
    For each of the eight lettered checks, perform a mutation, observe, and restore.

    **The order matters and is not negotiable: assert the mutation actually landed before
    reading the check's result.** A substitution that silently failed to match produces a
    green that means the opposite of what it appears to mean. Confirm the edit by reading
    the mutated line back, then run the check, then restore, then confirm the restoration by
    reading the line back again.

    Mutate in the SOURCE MODULE or in the CHECK's expected constant, never in
    `docs/Music-*.ics` — the material is the owner's and is the one thing in this phase that
    must not be touched. Suggested mutations, one per check:
      A — make `unfold` split on the literal CRLF instead of `/\r?\n/`; expect A to fail.
      B — remove the legacy grammar branch from `classify`; expect B to fail on class B = 0.
      C — key the join on format plus number, ignoring the venue word; expect C to fail with
          at least one piece dated after its night.
      D — change one pipeline rule's anchor kind from `next_edition` to `self`; expect D to
          fail on the night's LiveCut.
      E — make `reconcile` emit an update for an unchanged row; expect E to fail.
      F — make the script print one parsed `SUMMARY`; expect F to fail. **Restore this one
          first and confirm it, before running anything else.**
      G — remove one member from a SQL `CHECK` vocabulary; expect G to fail.
      H — add `event_parties` to a non-comment line in `reconcile.ts`; expect H to fail.

    Record all eight in the SUMMARY as a table: check, mutation, mutation-landed evidence,
    observed result, restored evidence. An unproved assertion is an assertion nobody should
    trust, and this repository has said so once already.

    After the eighth restoration, run `node scripts/verify-ics-import.mjs` and
    `npm run build` and confirm both are green — the proof that the tree is back where it
    started, which is the half of a mutation proof that is easiest to skip.

    not the same as adding a runner; do the first and not the second.

    `verify:ics` among the gates it did not run. A green that does not say so is the defect.
