## What this plan may not do

1. **`.planning/` is tracked and this repository is PUBLIC.** Every line written here is an
   irreversible publication. The document names **roles** — *an account holding
   `door.operate` for the night* — never a person, never a shift, never who was actually
   there. **No night's date, no venue, no line-up.** The only date permitted anywhere in
   `39-DOOR-PASS.md` is the frontmatter `written:` field, which is the document's own date
   and is not a night.

2. **No test file, no framework, no fixture.** This repository has no test runner for the
   product. A written procedure with observable evidence *is* the evidence here, not a
   supplement to it.

3. **No Result may read anything but `pending`.** A table of ticks nobody earned is worse
   than an empty table, because it closes a phase.

4. **P6 does not enter this document as a step.** It writes to production, the only
   authorisation this project held was spent at 2026-08-11T11:15:24Z and is recorded
   exhausted, and this project lost 63 production rows to a verification script with no
   PITR. It appears **once**, as a named exclusion with its reason and its deadline.

## Two questions this plan records rather than answers

- **OQ3 — should the door get a runtime cache rule longer than 24 h?** Not decided in a
  plan. The phase ships with the existing runtime rules plus the warm-up step (§0.5). After
  the dark-room observation, the question goes back to `/gsd:discuss-phase` with a real
  reading attached: a cache lifetime for the door is a product decision about how stale a
  door may be, and the door's own gate says a stale surface is a hazard.
- **OQ4 — does D-39-07's list include `38-HUMAN-UAT` test 8?** Resolved as **yes, fold it
  in**, and the document says so **visibly** rather than quietly, so the owner can strike
  one line if they disagree. It is a dark-room, one-handed, minimum-brightness observation
  — the same room and the same minute as criterion 3. Leaving it out would force the second
  trip D-39-07 exists to avoid.
