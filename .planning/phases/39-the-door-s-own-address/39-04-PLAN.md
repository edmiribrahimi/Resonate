## Why the implementation did not move, and what that bought

Plan 39-02 left `ScannerClient.tsx` and the door's guard where they were, at
`src/app/(admin)/admin/scanner/`, and put only a thin `page.tsx` at the new address. That was
not an aesthetic choice. Measured:

- **Moving** the door's files into a `door/` directory would make `src/app/**/scanner/**`
  match nothing — control **A** red, and control **G** reporting *"non matcha alcun file"*.
- Putting the page at `src/app/door/page.tsx`, outside every route group, would match **no**
  domain module at all: `src/app/*.tsx` covers only direct children of `src/app`. The door's
  page would load `meta-gates.md` and nothing else.
- Keeping the implementation under `.../scanner/` and adding a thin page under `(admin)`
  leaves A and G green **but opens the coverage hole this plan closes**: the new page loads
  `access-gating` + `nextjs-architecture` and not `checkin-offline`.

So this plan is not tidying after a mistake; it is the second half of a placement decision
whose first half was made deliberately.

## What this plan may not do

- **Do not widen any other module's `paths:`.** Every widening re-measures the budget, and the
  margin is 805 tokens.
- **Do not raise `BUDGET_CEILING_TOKENS`.** `verify-persona.mjs` says it in its own failure
  message: *"restringere i paths o accorciare la prosa. NON alzare il tetto."*
- **Do not add a module to the no-`paths:` set** (control D). The six manual modules are fixed
  and any addition needs its own declared reason in the changelog.
- **Do not touch `docs/` or `.firecrawl/`.** Control F asserts they stay ignored **and**
  untracked; this repository is public and a publication is irreversible.
- **Do not write a night's date, a venue under negotiation or a line-up** into any file this
  plan touches. The changelog entry describes **structure**, never production content.
- **Do not decide OQ3 here.** Whether the door deserves a runtime cache rule longer than 24 h
  is a product decision, deferred to `/gsd:discuss-phase` after the dark-room reading. The
  gate this plan adds is about **which address gets warmed**, never about how long a warmed
  address stays valid.
- **Do not touch any file under `src/`.** This plan is persona-only.

## Phase closure

This plan can go fully green on its own — `verify:persona` is the one automatic check in this
repository that measures something real. **It measures coherence, not correctness.** A green
7/7 says the persona's files agree with each other; it does not say a gate is right. And the
phase still does not close before the end-of-v1.5 sitting (D-39-07).
