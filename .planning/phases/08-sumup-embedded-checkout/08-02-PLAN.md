  ```typescript
  interface SumUpCheckoutModalProps {
    checkoutId: string;
    onClose: () => void;
    onPaymentComplete: () => void;
  }
  ```

  **State machine:** `status: "loading" | "ready" | "success" | "error"`
  - `loading`: shown while SDK initializes (SumUpCardWidget hasn't called onLoad yet)
  - `ready`: card form is visible and interactive
  - `success`: payment succeeded (onResponse "success" received)
  - `error`: payment failed

  Also track `errorMessage: string | null` for error details.

  **Layout (follow project's dark theme + existing component patterns):**
  1. Full-screen overlay: `fixed inset-0 z-50 flex items-end sm:items-center justify-center bg-black/60 backdrop-blur-sm`
  2. Modal card: `w-full max-w-md rounded-t-2xl sm:rounded-2xl bg-card p-6` (mobile: bottom sheet style, desktop: centered)
  3. Header row: title ("Complete Payment" or "Payment Successful") + close button (X icon or "Close" text)
  4. Body:
     - `loading` state: show "Loading payment form..." text with muted color
     - `ready` state: just the SumUpCardWidget (loading text disappears)
     - `success` state: green success message "Payment received!" with subtitle "Your ticket is being confirmed..." -- then call `onPaymentComplete()` after 2.5 seconds via setTimeout
     - `error` state: red error box with errorMessage + "Try Again" button that resets status to "loading" (note: to retry, the parent should create a new checkout -- for now just close the modal; per user discretion this is acceptable)
  5. Render `<SumUpCardWidget>` when status is NOT "success": pass checkoutId, handleSuccess, handleError, handleLoad callbacks.

  **Callbacks (use useCallback):**
  - `handleSuccess`: set status to "success", start 2.5s timer for onPaymentComplete
  - `handleError`: set status to "error", extract message from body
  - `handleLoad`: set status to "ready"

  **Close behavior:** Close button always visible. Clicking close calls onClose(). Do NOT prevent closing during payment (user discretion).

  **Import:** `import SumUpCardWidget from "@/components/SumUpCardWidget";`
