  **src/components/SumUpCardWidget.tsx -- NEW file:**
  Create a reusable "use client" component that wraps the SumUp Card Widget SDK lifecycle. Follow the pattern from 08-RESEARCH.md Pattern 2 exactly:

  1. Declare global `Window.SumUpCard` TypeScript types at the top of the file:
     - `SumUpCardConfig` interface with fields: id, checkoutId, locale, showSubmitButton, showFooter, showEmail, email, donateSubmitButton, amount, currency, country, nonce, onResponse, onLoad
     - `SumUpResponseType` = "sent" | "invalid" | "auth-screen" | "error" | "success" | "fail"
     - `SumUpCardInstance` interface with: submit(), unmount(), update()
  2. Component props: `checkoutId: string`, `onSuccess: (body: Record<string, unknown>) => void`, `onError: (body: Record<string, unknown>) => void`, `onLoad?: () => void`, `locale?: string` (default "en-GB")
  3. Use `useRef<SumUpCardInstance | null>(null)` to track the widget instance.
  4. In `useEffect` (deps: [checkoutId]):
     - Guard: if no checkoutId or no window.SumUpCard, return early
     - If instanceRef.current exists, call unmount() first (handles React Strict Mode double-mount)

     - Cleanup function: unmount instance and null the ref
  5. Render: `<div id="sumup-card" />` -- this is the mount target for the SDK.

  Wrap onSuccess, onError, onLoad callbacks in useRef to avoid stale closures without adding them to useEffect deps. This prevents the widget from re-mounting when parent re-renders with new callback references.
