Integration strategy:
- AnimatedSection: Wrap major page sections (headers, content areas). Server Components stay server -- wrap their JSX output in AnimatedSection (a client wrapper).
- StaggeredList + StaggeredItem: Wrap list containers and individual items. For Server Components that render lists, the map() output gets wrapped.
- PressableCard: Replace the outermost div of interactive cards. Remove active:scale-* from that element.
- PressableButton: Replace primary action buttons. Remove active:scale-* from that element.
- scrollTriggered={true}: Use on content sections below the fold on long pages.
- Keep CSS active:scale-* on: MobileNav links, StaffNav tabs, small utility buttons (copy, close, dismiss). Only upgrade to Motion where the enriched feedback matters.

CRITICAL: When wrapping content in a Server Component page with a client animation wrapper:
- Do NOT add "use client" to the page
- Import the animation wrapper (it's "use client")
- Wrap the JSX output: <AnimatedSection><existing JSX></AnimatedSection>
- This works because the Server Component renders its content and passes it as children to the client wrapper

**A. StaggeredList on list pages (UI-07):**

Pattern for wrapping lists:
```tsx
import { StaggeredList, StaggeredItem } from "@/components/motion/StaggeredList"

// Replace:
<div className="grid gap-4">
  {items.map(item => <Card key={item.id} />)}
</div>

// With:
<StaggeredList className="grid gap-4">
  {items.map(item => (
    <StaggeredItem key={item.id}>
      <Card />
    </StaggeredItem>
  ))}
</StaggeredList>
```
