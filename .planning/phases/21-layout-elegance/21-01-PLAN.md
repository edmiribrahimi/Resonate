1. Create `src/components/motion/AnimatedSection.tsx`:
   - "use client"
   - Import * as m from "motion/react-m"
   - Props: children, className?, delay? (default 0), scrollTriggered? (default false)
   - initial={{ opacity: 0, y: 20 }}, target={{ opacity: 1, y: 0 }}
   - transition={{ duration: 0.25, ease: "easeOut", delay }}
   - If scrollTriggered: use whileInView={target} with viewport={{ once: true, amount: 0.2 }}
   - If not scrollTriggered: use animate={target}
   - Render as m.div with className passthrough
   - This component powers UI-01 (enter animations) and UI-08 (scroll-triggered animations)

2. Create `src/components/motion/StaggeredList.tsx`:
   - "use client"
   - Import * as m from "motion/react-m"
   - Import { stagger } from "motion"
   - Export function StaggeredList and function StaggeredItem (named exports, NOT default)
   - containerVariants: hidden { opacity: 0 }, visible { opacity: 1, transition: { when: "beforeChildren", delayChildren: stagger(0.06) } }
   - itemVariants: hidden { opacity: 0, y: 15 }, visible { opacity: 1, y: 0, transition: { duration: 0.25, ease: "easeOut" } }
   - StaggeredList renders m.div with variants={containerVariants} initial="hidden" animate="visible"
   - StaggeredItem renders m.div with variants={itemVariants}
   - Both accept children and className props
   - This component powers UI-07 (staggered list animations)

3. Create `src/components/motion/PressableCard.tsx`:
   - "use client"
   - Import * as m from "motion/react-m"
   - Props: children, className?, onClick?, as? (HTML element tag, default "div")
   - whileHover={{ y: -2, boxShadow: "0 8px 25px rgba(229, 72, 77, 0.08)", transition: { duration: 0.2 } }}
   - whileTap={{ scale: 0.98 }}
   - Render as m.div with className passthrough
   - This component powers UI-11 (card hover elevation + press feedback)

4. Create `src/components/motion/PressableButton.tsx`:
   - "use client"
   - Import * as m from "motion/react-m"
   - Props: children, className?, onClick?, disabled?, type? ("button" | "submit", default "button")
   - whileHover={{ scale: 1.02, transition: { duration: 0.15 } }} (only if not disabled)
   - whileTap={{ scale: 0.97 }} (only if not disabled)
   - Render as m.button with className passthrough, disabled, type
   - When disabled: do NOT apply whileHover/whileTap (pass undefined for those props)
   - This component powers UI-06 (primary button micro-interactions) and UI-03 (press feedback)

5. Create `src/components/motion/CountUp.tsx`:
   - "use client"
   - Import { useEffect, useRef, useState } from "react"

   - Otherwise: use requestAnimationFrame loop with ease-out cubic easing (1 - Math.pow(1 - progress, 3))
   - Cleanup cancelAnimationFrame on unmount
   - Render: format ? format(display) : display
   - This component powers UI-09 (KPI counting animation), ready for Phase 22-23
