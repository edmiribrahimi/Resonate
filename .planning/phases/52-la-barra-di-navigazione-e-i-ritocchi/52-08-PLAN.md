## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonimo / attendee → `/gallery` | chi non tiene `gallery.view` bussa all'indirizzo |
| pagina (server) → Storage | la firma passa dalla SELECT sull'oggetto con la sessione di chi guarda |
| server → client | ai componenti arrivano URL firmati a scadenza, mai chiavi |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-32 | Elevation of privilege | `/gallery` raggiunta digitando l'indirizzo | mitigate | mappa (52-06) + `PROTECTED_PREFIXES` + guardia in pagina prima della lettura; `verify:routes` lega prefisso e allow-list |
| T-52-33 | Spoofing | open redirect via `?next=/gallery…` | mitigate | pattern ancorato `^\/gallery$`; `resolveNext` rifiuta per difetto |
| T-52-34 | Elevation of privilege | firma col service role | mitigate | modulo `server-only` che usa `createClient()`; grep nel comando di verifica: zero service role |
| T-52-35 | Information disclosure | chiave dell'oggetto al client o nei log | mitigate | ai figli solo `id → signedUrl`; log con categoria e numero, mai chiave o URL |
