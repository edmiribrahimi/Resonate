Flip the redirects to 308, walk them again, run the nine written procedures, compare the
container baseline, and write `34-VERIFICATION.md`.

Purpose: this is the plan where the phase stops being a set of source assertions. **A 308 is a
fourth monotone guard** in the sense of `meta-gates.md`: it is cached by the client and cannot
be withdrawn from a client that has already seen it, and there is no error tracking to notice
that a wrong one shipped. So the order is not negotiable — walk at 307, flip, walk again
(D-34-15).

The container baseline dumps `pg_policies` and runs persona matrices; **none of it can see a
route**. This phase edits no migration, so a green comparison is close to guaranteed and proves
only that no row-level permission moved. What moved is *who reaches which address*, and the only
instruments for that are the map's type-level assertions and a person signing in as each role.

Output: 308 shipped, nine dated observations, and a verification record that says what it cannot
prove.
</objective>
