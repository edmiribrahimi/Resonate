<objective>
Move the eight shared modules that live under `src/app/(organizer)/` but are imported from
everywhere else, and rewrite every import specifier that names them.

Purpose: `src/app/(organizer)/` cannot be deleted while **36 import statements across 28
files** reach into it — including five `(public)` event pages, ten `components/` files and
five `(admin)` pages. This is not part of the page collapse and it is not the deletion: it is
the prerequisite for both, and it is the largest mechanical hazard in the phase, because a
server action that stops being importable takes a public ticket purchase with it.

Nothing here changes a capability, a gate, or a behaviour. Every hunk is a path.

**On the five `(admin)/admin/events/**/page.tsx` files in this plan's file list:** only their
import lines change here. Their bodies are rewritten by plans 34-11 to 34-14 in Wave 4, which
is a later wave, so the two never race.

Output: eight modules relocated under `(admin)`, and zero references to `(organizer)` from
outside it.
</objective>
