Signature: `export default async function MenuPage({ params, searchParams })` where params has `slug: string` and searchParams has `order?: string`. Both are Promises (Next.js 16 pattern: `params: Promise<{ slug: string }>`, `searchParams: Promise<{ order?: string }>`). Await them at the start.

Logic:
1. Use `getServiceClient()` to fetch event by slug: `.select("id, title, date, slug, cover_image, is_published").eq("slug", slug).eq("is_published", true).single()`. If not found, call `notFound()`.

**localStorage helpers** (define at top of file):
```typescript
const STORAGE_KEY_PREFIX = "resonate_drink_tokens";

function storeGuestOrder(eventId: string, orderId: string): void {
  try {
    const key = `${STORAGE_KEY_PREFIX}_${eventId}`;
    const existing = JSON.parse(localStorage.getItem(key) || "[]") as string[];
    if (!existing.includes(orderId)) {
      existing.push(orderId);
      localStorage.setItem(key, JSON.stringify(existing));
    }
  } catch { /* localStorage unavailable (incognito) */ }
}

function getGuestOrderIds(eventId: string): string[] {
  try {
    const key = `${STORAGE_KEY_PREFIX}_${eventId}`;
    return JSON.parse(localStorage.getItem(key) || "[]") as string[];
  } catch { return []; }
}
```
