# Fase 52.1 Piano 10: la modalita' «Reorder» dei tier con @dnd-kit — Summary

In Manage tickets ogni lista di tier (una per serata, gli Event Pass a parte)
ha un pulsante «Reorder»: le card lasciano il posto a righe compatte (nome,
prezzo, maniglia a tre linee a destra), si trascina solo dalla maniglia, e
«Done» salva l'ordine intero con **una** chiamata a `reorderTiers`.

## Cosa e' stato fatto

**Task 1 — `0fa49b43`.** `npm install --save-exact` dei tre pacchetti:
`package.json` porta `6.3.1` / `10.0.0` / `3.2.2` senza `^`; `npm ls` pulito,
peer `react >=16.8.0` compatibili con React 19.2.3 (A1 tenuta: `tsc` e build
verdi). Nessun `hasInstallScript` sulle quattro voci `@dnd-kit` del lockfile
(c'e' anche `@dnd-kit/accessibility` 3.1.1, dipendenza transitiva di `core`).

`src/components/tickets/TierReorderList.tsx` (364 righe, `"use client"`):

- Sensori: `MouseSensor { distance: 4 }`, `TouchSensor { delay: 500, tolerance: 6 }`
  (D7), `KeyboardSensor` con `sortableKeyboardCoordinates` (D6, accessibilita' —
  nessun pulsante-freccia nell'interfaccia).
- Un `DndContext` per istanza → per lista (D5): un tier non passa in un'altra serata.
- Maniglia = `button` con `setActivatorNodeRef`, `aria-label="Reorder <nome>"`,
  classi della maniglia di `DrinkMenuManager` piu' `select-none
  [-webkit-touch-callout:none]` (A2); **`touch-none` solo li'** (D1).
- Vista normale = `children` (le `TierCard` del server) + «Reorder» solo con ≥ 2
  tier; in modalita' Reorder modifica e cancellazione non sono rese (D2).
- «Cancel» ripristina l'ordine d'apertura senza scrivere; «Done» chiama
  `reorderTiers(eventId, partyId, order)` una volta (D3). Cinque esiti a schermo:
  `ok` → `router.refresh()`; `stale_list` → «The list changed on another device —
  reload the page to see it» + «Reload»; `forbidden` → «You can no longer manage
  this night»; `failed` → «Could not save the order — nothing was changed»;
  eccezione → `[tickets.reorder_no_response]` in console e «No response from the
  server — the order may not be saved; reload to check» + «Reload».
- Annunci di `DndContext` in inglese con nome e posizione del tier, istruzioni
  per lo screen reader che ricordano che si salva con Done.

**Task 2 — `19af1373`.** `tickets/page.tsx`: le `TierCard` degli Event Pass
avvolte in `TierReorderList partyId={null}`, quelle di ogni serata in
`TierReorderList partyId={party.id}`; `tiers` = `{ id, name, price }` nell'ordine
del lettore unico (`sort_order, price, created_at`, piano 08). `AddTierForm`
resta fuori. Il docblock della pagina dichiara DBT-18.
