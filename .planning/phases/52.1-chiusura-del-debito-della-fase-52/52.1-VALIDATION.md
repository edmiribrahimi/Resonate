## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | **nessun test runner per il prodotto** (`package.json` senza `test`, zero `*.test.*`/`*.spec.*` — `CLAUDE.md` Guardrail 1). I gate sono `npm run build`, `npm run verify` (24 gate senza server), `npm run verify:persona`, piu' **procedure manuali scritte sul laboratorio** (`npm run dev:lab`), mai in produzione |
| **Config file** | `package.json` (script `verify*`), `scripts/verify-*.mjs` |
| **Quick run command** | `npm run verify:routes && npm run verify:breakpoints && npm run verify:tables` |
| **Full suite command** | `npm run build && npm run verify` (+ `npm run verify:persona` se si tocca `.claude/**`) |
| **Estimated runtime** | ~90 secondi (build) + ~10 (verify) |

---

## Sampling Rate

- **After every task commit:** il gate del dominio toccato (`verify:routes`, `verify:breakpoints`, `verify:tables`, `verify:media-strip`, `verify:capabilities`, `verify:persona`)
- **After every plan wave:** `npm run build && npm run verify` — **uscita 0**, precondizione di deploy (D-52.1-21)
- **Before `/gsd:verify-work`:** suite completa verde + procedure del laboratorio percorse e datate in `52.1-ESITI.md`
- **Max feedback latency:** ~100 secondi
