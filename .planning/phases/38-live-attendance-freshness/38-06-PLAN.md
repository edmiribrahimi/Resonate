<objective>
Make the state of the list visible, without adding an element to the busiest
screen in the product.

Purpose: LIVE-05 has two halves and a quiet screen satisfies only one of them. The
owner's first instinct was silence plus a band-only button; that combination makes
a clean screen indistinguishable from a screen that has not yet noticed, which is
the newsletter-form silent failure moved to the door. The resolution keeps the
quiet screen and adds the information to a row that already exists: the `12 / 40`
counter with its progress bar, which is where staff already look, becomes the
freshness display and the reload control.

And it is not cosmetic. This project has no error tracking — `package.json` has no
monitoring dependency — so a dead channel reaches a human only through this
screen. In a repository where a failure that matters must have an observable
effect rather than a log line, this **is** the observability.

Output: `ScannerClient.tsx` gains a 5-second tick, an age on the counter row, that
row as a real `<button>`, and a derived staleness band.

### The structural conflict this plan resolves rather than papers over

**F2.** CONTEXT.md says the band belongs to the same family as the existing
tone-tagged notices and should look like them. It must **not** be stored among
them. `setCacheNotices` replaces the array wholesale on every fetch — including on
each of the three early-return failure branches at `:670`, `:693` and `:727` — so a
band pushed into that array would be erased by a **failed** refresh, which is
precisely the moment it matters most.

**D-38-19.** The band is derived state, computed at render from `!channelLive ||
age > 5 minutes`, and rendered as its own element immediately above the notices
block, inside the same `role="status" aria-live="polite"` semantics and using the
same tone classes. `setCacheNotices` remains the single writer of its own array.
"Same family" means the visual and semantic family, not the same storage.
</objective>

    **The age.** Compute it at render as `performance.now() - lastFetchAtRef.current`.
    Never `Date.now()`: that can step backwards on an NTP correction at exactly the
    moment the network returns, and would print a negative age at the worst possible
    time. Format it as `updated Ns ago` below a minute and `updated Nm ago` above it.
    Before the first successful fetch there is no age — render nothing rather than
    `updated 0s ago`, which would be a claim.

    Write the rule beside the computation, in the file's own lexicon: this number is
    a display of local elapsed time. Nothing may refuse, admit or decide because of
    it; the only branch it drives is whether the band is shown. That is the line
    `checkin-store.ts` draws and `:740-745` already states for the clock drift.
