<objective>
Close the second finding named in the gap-closure scope: `scripts/verify-all.mjs:367`'s
reconciliation — the thing the file's own header calls *"the whole point of the file"* —
**cannot fail**, and would not change the exit code if it did.

Purpose: `plan` is built one entry per `OFFLINE` row and partitioned exhaustively into
`runnable` / `absentOptional` / `absentRequired`, so the left-hand side of the comparison is
always `OFFLINE.length + NEEDS_SERVER.length`. The refusals at `:208` and `:221` have already
guaranteed `declared ⊆ knownNames` and that every non-optional known name is declared, so the
right-hand side is the same number. The branch is unreachable on every input the earlier
refusals permit. And even reached, it only `console.log`s: the verdict block at `:411-448`
never reads it, so a run whose count did not reconcile would still print `VERIFY_OK` and
exit 0.

Both halves are the failure this file exists to prevent, and `.claude/rules/ai-engineering.md`
names the shape: *a gate no reachable situation violates is not a guard, it is a decoration
that makes something look watched.* The file already carries the right convention for the
verdict — a refusal is exit 2 and means the measurement did not happen — so the fix is to
reconcile against the thing that can actually drift and to route a mismatch through `refuse()`.

Output: one aggregate runner whose reconciliation compares verdicts obtained against entries
registered, refuses on a gap, and carries in its own header the concrete situation that would
trip it.

**What this does not close.** Nothing. This plan closes no requirement: DS-07, DS-08, DS-09
and RESP-01…RESP-04 all remain PARTIAL, and RESP-01 closes only after phase 41.2. The seven
IDs are listed in the frontmatter because this runner is the instrument through which every
one of their gates reports, not because it delivers any of them.

<interfaces>
The three exit codes this file already declares, and none of them moves:

- **0** — passed
- **1** — FAILED, a gate went red
- **anything else** — REFUSED, and *nothing was measured*. `refuse()` at `:168-171` prints
  `FATAL:` and exits **2**

Two gates have legitimate non-zero, non-1 exits and nothing in this plan may fold either
into a green: `verify:capabilities` REFUSES on any checkout without `.env.local`, and
`verify:touch-targets` is the one `optional` entry.

The four sets a name can land in after the run:
`results` (a verdict was obtained) · `NEEDS_SERVER` (declared, never run here, printed every
run) · `absentOptional` (declared absent, does not fail the run) · `absentRequired`
(MISSING, and that is a failure). Every registered name must land in one of them.
</interfaces>
