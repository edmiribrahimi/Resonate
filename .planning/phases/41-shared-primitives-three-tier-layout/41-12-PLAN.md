<objective>
Register the phase's new gates, give the repository one command that runs all of them,
and write the six observations no script will ever make — before the sitting that makes
them.

Purpose: `40-REVIEW.md` **WR-09 is open**: there is no CI in this repository and each gate
runs only when a human types its name. This phase takes the count from ten to sixteen.
**Six more gates nobody runs is not verification, it is six more files.** D-41-18 calls
this the cheapest high-value item in the phase, and it closes a Phase 40 warning at the
same time.

Nothing in this repository runs another script — ten `verify:*` entries, each a bare
`node scripts/…`, no `&&` chain, no runner, and no `.github/workflows/`. So the form of
each entry is copied and the **composition has no precedent**; it is designed here and
its two design decisions are stated rather than absorbed: a refusal is not a failure, and
a gate that needs a running server is not in the default run.

Output: `scripts/verify-all.mjs`; a `package.json` with seven new entries; and
`41-RELEASE-PASS.md` in the `40-RELEASE-PASS.md` mould, carrying H41-1 … H41-6.
</objective>

<interfaces>
**Measured on this tree on 2026-08-12:** ten `verify:*` npm entries, nine `.mjs` and one
`.sh`. Nine of the ten run with **no server and no credentials** and were observed
**exit 0**: `persona`, `tokens`, `routes`, `media-strip`, `semantic-separation`,
`sunset-gradient`, `no-header-identity`, `no-credit-account`, `capabilities`.

The tenth, `verify:redirects`, is the `.sh` one and **needs a running server**
(`npm run dev`) — its own header says so and says it therefore cannot be part of
`npm run build`. It does not go in the default aggregate run; it goes in a declared
`NEEDS_SERVER` list the runner **prints**, so a green states what it did not run.

The exit-code convention, from `verify-tokens.mjs:406-410` and used by every gate this
phase wrote: **0 = passed · 1 = failed · 2 = refused**, and *"a refusal is not a failure:
it means the measurement did not happen."* The aggregate must preserve that distinction
in its report, because collapsing them would reintroduce exactly the silent failure
`meta-gates.md` forbids.

The six new gates, if all were written: `verify-conversion.mjs` (G1 and G4),
`verify-dialogs.mjs` (G2), `verify-tables.mjs` (G3), `verify-touch-targets.mjs` (G5),
`verify-breakpoints.mjs` (G6), `verify-no-viewport-read.mjs` (G7). **G5 may not exist** —
plan 41-11 is permitted to end by deleting it, and this plan must handle that outcome
without pretending otherwise.
</interfaces>
