<objective>
Write the gate that makes criterion 1 mechanical: for every surface the manifest declares
converted, walk what that page actually reaches and assert nothing unconverted is in
there; assert every published primitive is imported by somebody; and assert the page's
outermost element is the shell at one of the three declared widths.

Purpose: *"no surface is left half-converted"* is a sentence until something walks the
import closure. And the phase's other failure mode is the one the tree already records —
`src/components/ui/Skeleton.tsx` is correct, complete and has **zero importers** while
102 hand-rolled `animate-pulse` blocks live in 20 files. Check C is that failure written
as a check.

G4 is a **check inside this script**, not a second file: it reads the same manifest, over
the same walk, and splitting it would mean two scripts resolving the same paths two ways.
That keeps the phase's new-gate count at six, which is the count `npm run verify` will
aggregate in plan 41-12.

Output: one `scripts/verify-conversion.mjs`, proven red four ways and green on the tree
as the previous plans left it.
</objective>

`PRIMITIVES` and `CONVERTED`, the last as `[route, pageFile, width, reason]` quadruples.
**`pageFile` is the exact path to open** — a work surface's files live in two directories
that are not nested in one another (`admin/(work)/events/[id]/tickets/page.tsx` and
`admin/events/[id]/tickets/RefundActions.tsx`), so a path-prefix resolver misses half of
a surface. Scope by the import closure, never by the path.

`scripts/verify-tokens.mjs` exports `listScannableFiles`, `liveLines`, `consumerPattern`
and `refuse` (exit **2**, distinct from exit 1). Its five-part header shape, its
"print what was counted" discipline (`:707-717`) and its verdict block (`:1041-1058`) are
the model.

`scripts/verify-semantic-separation.mjs:194-201` is the exemption shape: named exported
constants, each with the reason above it, collected into an `EXEMPT_PATHS` set the report
prints — *so a green states what it forgave*.

The legacy names are aliases in `globals.css:205-208`: `--background → --ground`,
`--foreground → --ink`, `--card → --surface`, `--card-border → --line`. A converted file
reads none of the four.
