<objective>
Close the fourth finding named in the gap-closure scope: `scripts/verify-dialogs.mjs:344`
recognises a hand-rolled overlay only when three literal substrings appear on one line, and the
third of them is one specific z rung. A nineteenth copy written at any other rung passes check B
in silence.

Purpose: check B is *"no second shell, except on the list"* — the mechanical half of DS-08's
claim that a dialog comes from **one** implementation. The eleven incumbent overlays happen to
carry the same rung, but the rung is not what makes something an overlay: `41-UI-SPEC.md` §10
keeps that rung declared for anything that must clear the navigation **without being modal**,
which is precisely why it is a poor signature. A copy written one rung up or down, or with a
different arbitrary rung, is invisible — and an invisible copy is the *"gate that went quiet
while the thing it tracked is still there"* shape this file's own header warns about, absent
from the four things it lists a green as not meaning.

There is a second, cheaper defect in the same three lines and it points the other way:
`line.includes` on the positioning utility also matches that utility inside a longer word, which
is a red on a correct file — the failure mode §0 rule 3 says gets a gate switched off.

Output: a matcher keyed on the shape of an overlay rather than on one rung, bounded so it cannot
fire inside a longer word, proving itself on three fixed probes on every run.

**What this does not close.** DS-08 remains PARTIAL and is not ticked. This gate reads class
strings and import clauses, never behaviour: whether Escape closes the panel, whether the sheet
rises from the bottom edge below 768px and whether the page behind it scrolls are **H41-2**, a
person at two widths, and research assumption **A2** — background scroll lock under
`showModal()` — is still explicitly open with nothing reported. Fourteen copies still stand on
`REMAINING`, and `RevealVenueDialog.tsx` — the interface of a monotone, irreversible guard — is
among them. Nothing here converts one.
</objective>

**The convention this file already keeps, and which the new matcher must keep.** Utility class
names are never written as complete literals in the source — the incumbent builds them by
concatenation for a reason that is not style: a complete utility literal sitting in a scanned
file is a class string Tailwind can compile, and this phase has already emitted a malformed rule
from a comment (DEF-41-01). Every fragment of the new regexes is assembled the same way.

**Two declared exceptions, neither of which moves:** `Lightbox.tsx` is exempt from check B;
`MyMediaSection.tsx` is **not** exempt and is on `REMAINING`, and it is the reason the signature
is keyed on the shell rather than on the accessibility role.

**A limit this plan declares rather than closes.** A class string split across two lines by a
formatter is invisible to a line-oriented matcher, before and after this change. Matching across
lines is a different change with a different risk; the honest move is to add it to the list of
things a green does not mean, not to leave it unsaid.
