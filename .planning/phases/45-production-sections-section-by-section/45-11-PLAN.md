<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the row-level policy → what renders | The only boundary. The page guard and the middleware decide where a redirect happens; they stop nobody reading a row |
| a rendered value → a log, a title, a label, an analytics call | Four exits a value can take without anybody deciding it should |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-01 | Information disclosure | a space's name and address | mitigate | the read is cookie-bound, so the policy decides; the value travels from the query into a table cell and nowhere else — no `console.*`, no thrown message, no page title, no `aria-label`, no analytics call |
| T-45-02 | Information disclosure | the failure branches | mitigate | `code=… message=…` only; the error object never reaches a log, and neither does PostgREST's row-carrying field |
| T-45-13 | Spoofing | a score, a capacity, a stage | mitigate | scores computed and shown per format through the one renderer that cannot draw a bare number; capacity rendered missing rather than inferred from the band; the badge has no branch that produces nothing |
| T-45-04 | Elevation of privilege | the binding move | mitigate | the entry moves to the routes branch **in the same commit as the page**, with `alsoGatesTables` carried; a page bound to a table-only key is unreachable for everyone with no error at all |
| T-45-05 | Denial of service | the middleware bundle | mitigate | the addresses were checked against the pattern list in plan 45-03 and `npm run verify:routes` is an acceptance criterion here |
| T-45-SC | Tampering | npm/pip/cargo installs | accept | no package is installed; the primitives are Phase 41's |
</threat_model>
