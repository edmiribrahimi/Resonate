<objective>
The location section becomes writable: a space can be created, corrected, answered, moved
between stages and retired — and none of those can produce a row the domain says cannot
exist.

Purpose: D-45-05 puts the authoring inside the app, and D-45-06 makes the key that reads a
section the key that writes it. D-45-18 is the price of that decision and it binds every
line of this plan: what a whole-error log line can now leak is the address of a space under
negotiation, into logs nobody watches, because this project has no error tracking.
Output: one Server Action module, one form, one dialog, one page wired.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the browser → a Vercel function | D-45-05's accepted cost: the names of spaces under negotiation now travel through a server, which Phase 44 declined for the calendar (D-44-26) |
| a `"use server"` export → the public internet | **Every** export of such a module is an endpoint |
| a failed write → a server log | PostgREST returns the **failing row** in the error's third field, and the failing row here carries an address |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-02 | Information disclosure | every failure branch | mitigate | `code=… message=…`, an identifier and nothing else; the error object never reaches a log and neither does the field that carries the row. **Critical, not hygiene**: what leaks here is the address of a space under negotiation, into logs nobody watches |
| T-45-04 | Elevation of privilege | the gate | mitigate | asked **first**, once, unexported; the service client constructed after it. An ordering slip turns an act into an unauthenticated write path and no build would see it |
| T-45-13 | Spoofing | a stage, an answer, a provenance | mitigate | `createSpace` takes no stage; `recordAnswer` requires its source; `setAttribute` requires its provenance; `recordExtendedHoursStance` cannot write `not_asked` and has no inference path |
| T-45-01 | Information disclosure | the dialog and the form | mitigate | the confirmation names no space; the address is a field on a gated form and appears in no title, no label and no log |
| T-45-15 | Repudiation | a space that left the race | mitigate | no delete export exists; `exitSpace` writes a reason and a date together, and the XOR constraint refuses a row that says one without the other |
| T-45-SC | Tampering | npm/pip/cargo installs | accept | no package is installed; no validation library is added, deliberately |
</threat_model>
