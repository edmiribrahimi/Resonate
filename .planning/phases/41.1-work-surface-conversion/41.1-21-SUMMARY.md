## 4. The empty-state selection — quoted, with which node under which condition

Gap G-d. The primitive draws its empty node when the rows it was handed are
empty, and it takes **one node per render**. So the choice happens in the caller,
before the hand-over:

```tsx
const emptyNode =
  buyers.length === 0 ? (
    <p className="text-base font-semibold text-ink">No tickets sold yet</p>
  ) : (
    <p className="text-base font-semibold text-ink">
      No results for &quot;{search}&quot;
    </p>
  );
```

| Condition | Node passed | What it says |
|---|---|---|
| `buyers.length === 0` — the unfiltered list is empty | the first | no tickets sold yet |
| `buyers.length > 0` and `filteredBuyers.length === 0` | the second | no results for the term typed |
| `filteredBuyers.length > 0` | either; the primitive draws rows and neither is rendered | — |

**A search that matches nothing cannot render the no-sales wording**, because the
first node is reachable only when the unfiltered array is empty, and an empty
unfiltered array cannot be filtered to something non-empty.

**The third empty state is the tier region's** — `No tiers configured` — and it
stays where it was, hand-written, outside the table. Three sentences, three
conditions, none of them collapsed.

## 11. Deviations from plan

### 1. `[Rule 1 — a rendering defect the plan's slot table would have shipped]` the discount column is a `mark`, not `meta`

- **Found during:** Task 1
- **Issue:** the plan's slot table assigns the discount to `meta`, *"conditional;
  the cell returns nothing when there is none"*. Measured against the primitive:
  the card branch renders a meta column's label **per column, not per row**
  (`DataTable.tsx:446-458` — the label comes from `labelOf(column)` and the
  ternary that guards it tests the *label*, never the cell's output). A row with
  no discount — which is most rows — would have read `Discount:` followed by
  nothing: a card asserting a labelled fact that does not exist.
- **Fix:** the column takes the `mark` slot, whose card markup is a bare span
  (`:430-433`) and is therefore invisible when the cell returns `null`. That is
  also exactly what the deleted card branch did: a pill when there was a code,
  and nothing at all when there was not.
- **Refused alternative:** suppressing the label with an empty `cardLabel`. It
  compiles and it renders, and it puts an unlabelled fact in the slot whose whole
  contract is that its facts are labelled.
- **Effect on the money floor:** none. The tier is still a `mark`, neither mark is
  an amount, and §3.1's sentence is unchanged — that is the point being recorded.
- **Committed in:** `8228d4e`

### 2. `[criterion arithmetic]` the tables gate prints `REMAINING = 0`, not 1

### 3. `[Rule 2 — a column labelled by nothing]` the actions column gained a name for a screen reader only
