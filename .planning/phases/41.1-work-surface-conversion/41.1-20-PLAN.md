<objective>
Convert the venue reveal panel and its confirmation dialog — the third knot, and
the one built on a **monotone** guard.

Purpose: `venue_reveal_sent` is a one-way switch. Once the mail has gone the
location is public; there is no annulment, because the screenshot exists. So the
rule for this plan is not *change nothing*: it is **work may only make the reveal
harder to trigger, never easier** — and changing a confirmation's focus target,
its button variant or its copy **is** touching that guard.

**And here the conversion argues for itself.** The dialog's existing autofocus
attribute at line 426 is **measurably inert**: React's attribute writer skips the
autofocus prop, so no such attribute ever reaches the DOM, and the user agent
focuses the first focusable element instead. Today the confirmation's focus
placement is unspecified in practice. After the conversion it is Cancel,
deliberately, placed imperatively after the modal opens. **That is a strictly
tighter guard** — which is why the monotone rule argues for this work rather than
against it. Stop condition 1 stands regardless: *"it should be tighter"* is an
argument and not an observation, so a person exercises it.

Output: two files converted, one dialog debt entry paid, one before/after focus
statement, and a written human procedure.
</objective>
