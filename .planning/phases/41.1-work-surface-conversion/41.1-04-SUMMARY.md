## Task 1 — both the sentence and the branch were deleted, and why one alone was the worse half

The plan asked the executor to **decide and say** which it did. **Both.**

- **The sentence.** The exit-2 list in the header used to promise a refusal for
  *"the single `className={FOCUS_ROOT}` sitting outside the window"*. That
  clause is gone. It is quoted verbatim in its own place (`:330`) beside the
  measurement that retired it — the house shape `PageShell.tsx:42-46` uses for a
  claim it had to withdraw.
- **The branch.** The three-conjunct `refuse()` that raised it is gone too.

**Deleting only the sentence** would have left a `refuse()` nothing can reach
sitting in a file whose own prose says *"a branch no situation can reach is a
decoration that makes something look guarded"* — the header would be honest and
the code would still be carrying the decoration the header stopped describing.
**Deleting only the branch** would have left the header promising a refusal that
no longer exists even in dead form: a strictly worse lie than the one it started
with. The plan's argument for the direction — *"deleting the sentence adds no
code and removes the lie"* — is only true if the code goes with it.

**The unreachability, re-derived on this tree rather than cited.** Reaching the
branch required `propertiesInFocusBranch.length === 0`. The shape-mismatch
refusal above it (`SHAPE CHANGED`, at what is now `:1856`) fires on exactly
`length === 0 && !focusShapeMatched`, so anything arriving below it with no
property in the window arrived with the frozen shape **matched**. A matched shape
puts `<div className={FOCUS_ROOT}>` at window position 3 by construction, so the
one render site is inside the window and the third conjunct cannot hold while the
first two do.

**The gap is declared, and its counterpart is named.** In the fence vocabulary
`verify-dialogs.mjs:55-61` established: *a focus-root render site outside the
frozen window is **UNMEASURED, not approved***. What reaches the same ground is
`SHELL_CODE_OUTSIDE_WINDOW_DIGEST` — it hashes every non-empty trimmed line of
the shell's live code outside the window, so a render site moved out there moves
that digest and refuses under `SHAPE CHANGED`. Naming it is the point: a gap
declared without its counterpart reads as a hole, and a gap left undeclared reads
as coverage.

### The `existsSync` class, second half

`existsCaseExact(relPath)` in `conversion-manifest.mjs` matches every path
segment **byte-for-byte** against the real directory entries from `ROOT` down.
`existsSync` is still asked first, as a fast negative only. The three checks in
`checkManifest()` — `CONVERTED`, `SPINE`, `PRIMITIVES` — all call it, and each of
the three refusal messages names the path and names the case typo as one of the
possibilities.

Written beside the helper: **this is the second half of a class whose first half
is `verify-dialogs.mjs:1191`, repaired by plan 41.1-02 in the same wave**
(`41.1-RESEARCH.md` §4.6 row 4 names both together). That sibling repair could
not be observed from this worktree — 41.1-02 runs in its own — so the sentence
records the plan's assignment, not a measurement of the sibling's tree.

**What it deliberately does not do**, written down rather than discovered: it does
not normalise Unicode. APFS can store a decomposed (NFD) name a source file
spells composed (NFC), and this would call those different. Every path in the
manifest is ASCII, so the condition is not reachable today.
