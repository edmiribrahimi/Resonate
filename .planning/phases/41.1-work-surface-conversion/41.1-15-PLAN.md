## Stated before the diff — this is a money surface

**What is opened:** the finance page, its loading file, and the transaction list.
**What is not:** `src/components/admin/RefundDialog.tsx`, which the transaction
list opens from a row. That file is one of the knots and belongs to plan
41.1-17, in the last wave, with its own impact analysis (D-41.1-19).

**Therefore `/admin/finance` is NOT declared converted by this plan.** Check A
walks into `RefundDialog.tsx` through the transaction list, so a declaration
before plan 41.1-17 lands would fail on that file's palette hits — correctly.
The declaration is made by the **final** reconciliation, plan 41.1-24. Say so in
the SUMMARY; a surface that looks converted and is not declared is otherwise read
as an oversight.

**The three stop conditions, verbatim, because two of them bind here:**

1. **`venue_reveal_sent` is monotone.** Work may only make the reveal harder to
   trigger, never easier. Nothing in this closure reaches the reveal — asserted,
   not assumed: the grep is in the acceptance criteria.
2. **A payment reaching `completed` corrects forward.** **No conversion changes a
   status transition, a refund amount, an idempotency key or a webhook path.**
   The status badge is a *rendering* of a status and this plan changes only how it
   is drawn. If converting appears to require touching a transition, **halt and
   return to the owner.**
3. **A series progressivo is already on a poster.** No conversion renumbers,
   re-sorts or re-derives one. Nothing here does; stated so it stays true.

**Classification: Structured, at the boundary of Critical.** The files opened
render money and open a refund; they do not move money. The moment a diff line is
not a class string, a JSX structure or an import, that classification has expired
and the work stops.
</impact_analysis>
