   manifest's primitives list — report the entry text, do not write it.

   checked state, its name and its submitted value are behaviour** — the primitive
   carries them through unchanged.

   defines a new control.

   payment: this plan touches no price arithmetic, no order, no token and no
   refund. If a conversion would require touching one, that is a halt.

   measurements.** `src/app/(public)/events/[slug]/menu/EventQRCode.tsx` is the
   **sixth** entry on D-41.1-19's authorized file list, **added 2026-08-13** by a
   decision taken on its own terms after the earlier inclusion — an engineering
   inference drawn from the file's own measurements — was refused. The measurements
   (69 lines; props are `url` and `eventTitle` only; no amount, no address, no
   payment path) **support** that decision; they did not **make** it. A measurement
   showing that a crossing is safe is not the owner having authorized it. Cite the
   decision, never the measurement, wherever this file's presence is explained —
   including in the SUMMARY.

   It remains a `(public)` file shared with the bar's menu page, which is Phase
   41.2's, so the crossing is still **declared, not discovered**: the SUMMARY names
   it as a 41.2-adjacent file converted early because a work page's closure reaches

   converted.

   (D-41.1-19, standing rule, 2026-08-13). This phase converts *whole* closures, so
   an execution can walk into a file nobody planned for. If a closure this plan

   `RevealVenueDialog.tsx`, `EventQRCode.tsx` — **stop and report it. Do not
