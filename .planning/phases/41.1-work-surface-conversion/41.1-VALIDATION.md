# Phase 41.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `41.1-RESEARCH.md` §5.3 and §Validation Architecture.

---

## Why `nyquist_compliant` is `false`, and deliberately so

**There is no test runner for this product.** `package.json` declares no `test`
script and no `*.test.*` / `*.spec.*` file exists under `src/`. Installing one is
a milestone-sized decision that appears in none of this phase's requirements and
is refused by **D-41-20**.

What exists instead are **16 structural gates**. They assert class strings,
import clauses and declarations — **never behaviour, and never a rendered pixel.**
Every row below is scoped accordingly: where a claim cannot be scripted, the row
says **manual** and names the procedure, because in a repository without tests the
written observation is the only proof that will exist.

Phases 31, 36 and 41 all closed with `nyquist_compliant: false` for the same
reason. Setting it `true` here would be a claim about coverage that no command in
this repository can support.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | **none for the product** — by decision, not by omission (D-41-20) |
| **Config file** | none, and **no Wave 0 gap follows** |
| **Quick run command** | `node scripts/verify-<gate>.mjs` — the one gate whose subject the task touched |
| **Full suite command** | `npm run verify` (16 gates; refusal counted separately from failure) **and** `npm run build` (Next's typecheck, and the only thing that catches a type error) |
| **Estimated runtime** | `npm run verify` ≈ 3s measured · `npm run build` ≈ minutes |

> **A refusal is not a failure.** `verify-all.mjs` prints exit 2 as *nothing was
> measured*, separately from exit 1. A green that contains a refusal has not
> verified the thing it appears to have verified.

---

## Sampling Rate

- **After every task commit:** the one gate whose subject the task touched, plus
  `npm run build` if any file under `src/` changed.
- **After every plan wave:** `npm run verify` in full, **plus** the D-41.1-16
  reconciliation task — which diffs **entries, not counts**, because four distinct
  mechanisms in this phase family have already made a count fall for the wrong
  reason — **plus** H41-1 at three widths on every surface that wave converted
  (D-41.1-18, per wave and never accumulated to the end).
- **Before phase close:** `npm run verify` green, `npm run build` green, the four
  criteria's commands producing their stated output, and every owed human
  observation recorded — ticked or `human_needed`, never assumed.
- **Max feedback latency:** seconds for the gates; **one human pass per wave** for
  everything the gates cannot see.
