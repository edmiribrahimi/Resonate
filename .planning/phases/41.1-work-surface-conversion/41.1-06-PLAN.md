<conversion_rules>
These bind every task in this plan and every conversion plan in this phase.

1. **This plan edits no file under `scripts/`.** D-41.1-22: the wave's
   reconciliation plan is the single declared owner of every gate edit in the
   wave. A `REMAINING` list is one file every plan would want to edit, which makes
   the partition rule unsatisfiable any other way. **Report** in the SUMMARY: (a)
   the exact `CONVERTED` entry text for each page in the shape
   `[route, pageFile, width, reason]`, and (b) every `REMAINING` entry this plan
   emptied, by gate and by path. Do not delete one.
2. **No behaviour change.** The sentence is `conversion-manifest.mjs:372`'s and it
   goes into every reported manifest reason: *"no query changed, no column added,
   no capability check touched, no action payload altered"*. Before committing,
   grep the diff for `select(`, `CAP.`, `.eq(`, `.filter(`, `capabilities.has`
   and `redirect(` and paste the result into the SUMMARY. **A conversion diff
   that is not entirely class strings, JSX structure and imports is the warning
   sign.**
3. **Never spell a Tailwind class string inside a comment.** Tailwind's source
   detection cannot tell a description from a use and `.planning/` is in its scan
   path (`PageShell.tsx:64-67`, `layout.tsx:138-141`; DEF-41-01 open).
4. **`sm:` is a map, not a rename.** A three-column grid at the small prefix
   becomes two columns at `md` and three at `lg`, gaining the middle step it
   skipped. Read `41-UI-SPEC.md` §2.3 per class, never per prefix (pitfall P6).
5. **The focus expression is imported, never re-spelled.** Every
   `focus:outline-none` site takes `FOCUS_RING` exported from
   `src/components/ui/Button.tsx:71`. `focus-visible:`, never `focus:`; the 2px
   offset is load-bearing.
6. **A `Badge` that is a link or a button is a `Chip`, not a `Badge`**
   (`41-UI-SPEC.md` §8.5). That sentence is the difference between a correct file
   and a 20px target.
7. **The third stop condition applies here even though the other two do not:** a
   series progressivo is already on a poster — **no conversion renumbers,
   re-sorts or re-derives one.** Nothing in these three pages does today; it is
   stated so it stays true. These pages touch no money and no venue reveal.
8. **Declare the surface's own closure before starting.** Run the closure command
   in task 1 and convert every file it lists that carries a class attribute — the
   gate's definition of *whole* **is** the import closure.
9. **The authorized file list is closed, and a file outside it is a halt**
   (D-41.1-19, standing rule, 2026-08-13). This phase converts *whole* closures, so
   an execution can walk into a file nobody planned for. If a closure this plan
   declares reaches a file that is neither in this plan's `files_modified`, nor
   already converted, nor on D-41.1-19's authorized list — `EventForm.tsx`,
   `RefundDialog.tsx`, `RefundActions.tsx`, `VenueRevealPanel.tsx`,
   `RevealVenueDialog.tsx`, `EventQRCode.tsx` — **stop and report it. Do not
   convert it, and do not conclude that it is safe.** The list grows **by owner
   decision or not at all**, however small the file and however well measured. The
   sixth entry is the precedent: it was measured, the measurement was right, and
   the inclusion was still refused until the owner decided it. Record the file, its
   measurements and the surface whose closure reaches it in the SUMMARY as a
   question owed to the owner, in the same shape the knot plans use for their stop
   conditions.
</conversion_rules>
