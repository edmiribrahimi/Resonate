### `npm run verify` does not exit 0 here, and making it do so would violate D-41.2-04

The plan's criterion asked for exit 0 with no refusal. The measured result is **exit 2 with
exactly one refusal**, and the refusal is environmental rather than a fact about the tree:

```
verify:capabilities  exit 2  REFUSED
FATAL: missing environment variable(s): SUPABASE_ACCESS_TOKEN, NEXT_PUBLIC_SUPABASE_URL.
Set them in .env.local (gitignored) or in the environment. Nothing was measured.
```

`ls .env.local` in this worktree: **no such file**. The gate refuses **before measuring
anything**, so its verdict cannot be a function of this diff — and neither converted file has
a capability surface.

**The credentials were not supplied, and that is a decision rather than an omission.**
D-41.2-04 says no worktree runs against `.env.local` in this phase, because doing so points a
measurement at production, and this repository has an incident — D12 — in which a
verification destroyed 63 production rows across seven tables that were never recovered,
because PITR is not enabled. Turning this refusal green would have required exactly the thing
that decision forbids. **The honest state is recorded instead: fifteen gates reached a
verdict, all fifteen passed, zero failed, and one measured nothing.**

### What no green here proves

Nothing above observes a rendered box, a focus ring, or a sheet on a phone. The 44px floor,
the sheet-versus-window boundary and the visible focus on Cancel are **human rows**, and this
phase plans as 41 and 41.1 did: every human row `pending`, batched to the end-of-v1.5 sitting
(D-41.2-04). The written procedure both files need:

1. On a phone-width viewport, open the refund confirmation. **Cancel is focused visibly, the
   panel enters from the bottom edge, Escape closes it, and the page behind does not scroll.**
2. Press Enter immediately on open. **Nothing is submitted.**
3. Force a refusal. **The sentence appears above the buttons, not below the fold.**
4. Close by each of the three routes — the close control, Escape, Cancel — and reopen.
   **No stale refusal survives any of them.**
5. At tablet width and above, the same panel is a centred window.

The guest question cannot be observed at all until somebody re-enables it, which is the
point of leaving the path warm rather than deleting the file.
