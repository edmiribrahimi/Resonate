## 1. The share control, first — because it is the one that publishes

A share sheet is a publication and a publication of a place is not recallable.
So this section comes before the conversion work, and its enumeration was
**rebuilt by reading the file** rather than carried forward from a document —
`venue-secrecy.md`'s rule, because such a list is dated by construction.

### 1.1 The three strings, with the source of each

| # | Field | Value | Where it comes from |
|---|---|---|---|
| 1 | `title` | the `title` prop | the event row's own title, passed at the page's single mount site |
| 2 | `text` | the `description` prop, falling back to (1) | the event row's description, same mount site |
| 3 | `url` | the current page's own URL | the browser, i.e. this route's slug |

**The clipboard branch writes (3) and nothing else.** The share-sheet branch
hands over all three.

**The row those two props come from carries no place.** The event select names
ten columns and not one of them is a place, a street or a map. The columns that
*do* carry a place belong to the **night** rows, which are a different select
feeding a different variable — and neither reaches this control.

### 4.2 D-41.2-18-A — cancelling an RSVP is not the destructive rung

It was a red fill. It is now the secondary rung, and **this is a visible change.**

The rung follows the **act**, not the file it lives in. Cancelling destroys
nothing recoverable: the row goes, and pressing again puts it back. That is not
an assumption — the action was read, and it applies **no capacity ceiling and no
window** that could refuse the second press. Painting a reversible act in the
critical semantic spends, on something recoverable, the one colour this system
has for saying *this cannot be taken back* — and on this surface, where an
irreversible act genuinely exists a few components away, that colour has real
work to do.

Same argument as the sign-out control in wave 6, **re-derived on this act** rather
than inherited from it: an argument that declines to cite an available precedent
and re-checks the act is worth more than one that cites it.
