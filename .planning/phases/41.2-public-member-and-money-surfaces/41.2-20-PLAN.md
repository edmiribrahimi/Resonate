> Measured in wave 0: `verify:capabilities` **refuses with exit 2** when `.env.local`
> is absent, printing *"Nothing was measured"* **before touching anything**. A
> worktree has no `.env.local`, and putting Supabase credentials into one is

> executor-side bar is:
>
> **all 15 gates that reach a verdict pass, 0 fail, and `verify:capabilities`
> refuses for want of credentials.** A refusal that names its missing input is a
> gate declining to measure, not a gate failing — and it is distinguishable from
> both a pass and a failure, which is the whole point. Quote the tail of the run
> showing the counts.
>
> **Do not make it green.** Not by adding credentials, not by skipping the gate,
> not by rewording the criterion. The full 16/16 suite is run by the orchestrator
> in the main checkout after this wave merges, where `.env.local` exists.

previous pass's batch field already commits, alongside the other pass documents
queued for it. A second sitting would not add attention; it would split it.

reconstructed afterwards is a memory and not a measurement.

Output: two documents, every Result `pending`, every criterion a number.
