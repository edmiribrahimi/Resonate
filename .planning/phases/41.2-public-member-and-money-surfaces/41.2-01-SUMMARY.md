## Deviations from Plan

### 1. `npm run verify` cannot exit 0 on this worktree — recorded, not worked around

- **Found during:** Task 1, before the dry run began.
- **Issue:** the plan's acceptance criteria for Tasks 1 and 3 require
  `npm run verify` to exit 0. It exits **2**: `verify:capabilities` refuses for
  want of `SUPABASE_ACCESS_TOKEN` and `NEXT_PUBLIC_SUPABASE_URL`. `ls -la` on the
  worktree root shows `.env.local.example` and **no `.env.local`** — a worktree
  does not receive gitignored files.
- **Resolution:** **not repaired, deliberately.** Supplying those credentials
  would point a gate at production, which D-41.2-04 forbids and which this
  repository has D12 behind. Recorded as §0 of the findings document with the
  honest reading every later plan should apply: *15 passed, 0 failed, 1 refused,
  and the refusal is `verify:capabilities`*. The refusal is a **constant** — it
  was identical before, during and after the dry run — so it contaminates no
  figure above.
- **Files modified:** none.

### 2. The plan's `verify` block for Task 2 greps four files; the census ran over ten

- **Found during:** Task 2.
- **Issue:** the plan's automated verify names four page files. The action text
  requires the census over all ten, and the four named are the *research's* four —
  which §7.1 shows to be wrong.
- **Resolution:** ran the census over all ten and recorded the six measured zeros
  as measured zeros. The plan's four-file grep was also run and its output is in
  the document; it agrees.
- **Files modified:** none.

### 3. Line numbers for three of the four silent catches had drifted

- **Found during:** Task 3.
- **Issue:** `41.2-RESEARCH.md` §3.5 cites `GuestTokenDisplay.tsx:23-30`,
  `:37-39`, `:405-411`. Re-read, they are `:20-31`, `:34-40`, `:403-410`.
- **Resolution:** recorded the re-read numbers with a note that the predicate text
  is the anchor, not the number — a stale line number matches nothing, which reads
  like a green.
- **Files modified:** none (documents only).

**No Rule 4 escalation was needed, and no deviation touched a source or gate file.**

## What I Refused To Do, And Why

**Fix a silent catch.** Four are recorded and none is fixed. Repairing one while
converting a class string changes behaviour on the money path under a visual
mandate — stop condition 2 in a different costume. The sentence is written into
`deferred-items.md` itself so the next reader does not re-derive it.

**Supply the missing Supabase credentials to make `npm run verify` exit 0.** That
would satisfy a checkbox by pointing a gate at production. D-41.2-04 forbids it;
D12 is why.

**Widen a touch-target exemption to absorb any of the 81 reds.** None of the 81 is
a gate reddening on a correct file — an interactive element declaring no height is
not a parser false positive, it is a box nobody decided. §0 rule 3 is not
triggered, and the precedent `DEF-41.1-24-01` was closed by a signed contract edit
rather than by widening anything.

**Audit the wallet route's upstream venue entitlement.** DI-41.2-05 records the
exit and explicitly declines the wider claim: whether `data.venue` is entitled is
decided on a route this plan did not open. Claiming it audited would be the worse
outcome.

**Edit any page file to apply a disposition.** The surface plans own those lines;
two authors on one line is how a disposition becomes a conflict.
