<objective>
Convert the member dashboard's satellites: the media section, the two account
sections, and the three authentication controls.

Purpose: one of these six is **a declared gap in the pattern map, and it is a gap
because the gate and the tree point in different directions.** The media section
is named by the dialogs gate as *not exempt* and it sits on the debt list — yet
what it actually renders is a full-bleed viewer at a heavy scrim, which is
precisely what the declared **permanent exemption** in the same gate exists for.
Putting the sheet-and-window dialog primitive around a full-bleed photo would be
the *correct file goes red* shape the contract's own rule forbids. Delegating to
the exempt viewer removes the shell — which is what takes the file off the debt
list — without widening an exemption and without editing a gate.

**But no converted file in this tree has replaced its own overlay with that
viewer**, so there is no diff to copy, and the viewer's item type may not match
what this section holds. That is why the disposition is decided **in writing,
before the diff**, and why the viewer's own type is read first rather than during.

Output: six files, one debt entry made stale by delegation rather than by a
shell swap, three refusal paths kept readable.
</objective>
