## 6. Deviations from plan

### D-41.2-07-A — `MembershipCardView` is **not** put on the `Card` primitive

**Found during:** Task 3. **The plan says** *"card shells become `Card`"*.

`ui/Card.tsx:51` fixes one ground, one line-token edge and one padding step. This
card is an accent-bordered gradient (`border-accent/30`, `bg-gradient-to-br`)
with **two** internal padding zones, and it is the surface's whole visual
identity. Adopting the primitive would delete the edge, flatten the gradient and
reflow both zones — a **redesign of the object a person presents at an entrance**,
performed under a mandate whose own rule is that width may change layout and
never what the thing is.

The token rename clears both gates that were asking anything of the file (check A
→ 0, check B → 0) and, because the four legacy names are declared **aliases**
(§3.3), it moves no computed value at all. The primitive **is** adopted next
door, in `CopyReferralLink.tsx`, where the shell genuinely is the plain card
shell — so this is a disposition, not an exemption.

**Consequence recorded for four later plans.** The same accent-gradient shape
recurs at `dashboard/page.tsx:407,449`, `DrinkTokenCard.tsx:116`,
`GuestTokenDisplay.tsx:344` and `tickets/[id]/page.tsx:119`, all in later waves.
This file is the first of them to convert; the disposition is written into it so
the next four read a decision rather than take a vote.

**Commit:** `a496a80`.

### D-41.2-07-B — the referral input stays raw and declares the floor itself

**Found during:** Task 3. `ui/Input.tsx`'s props are the intrinsic input
attributes minus the ones it owns — **it does not take a `ref`** — and the ref is
not decoration: it **is** the fallback copy path. In a browser without the
clipboard API the only route that works is selecting that element and asking the
document to copy the selection. Adopting the primitive would have **deleted the
only working route silently, while looking like an adoption**.

So the element stays raw and carries the control contract by hand: the 44px
floor (`min-h-11`), the control boundary, the sunk well, the ink, and the **one
imported focus expression** — `FOCUS_RING`, read from the ladder and spelled
nowhere. This is the criterion's own alternative: *a primitive **or** declares the
floor*. `verify-touch-targets` exits 0.

**Commit:** `a496a80`.

### D-41.2-07-D — an accessible name was added to that input

**Found during:** Task 3. Having declined the primitive, the control was about to
ship without the one thing the primitive makes a **type error**: a name. The
primitive's own docblock states the case — *"a field with no name is announced as
'edit text' and nothing else — a defect that renders, compiles and looks
correct."*

`aria-label="Your referral link"` was added. It changes no value, no handler and
no reported outcome, and it appears in the filtered diff above rather than
tucked away: **declining a primitive does not authorise declining the contract
the primitive enforces.** Declared here because it is the one line in this plan
that is not a class string, a JSX structure or an import.

**Commit:** `a496a80`.

### Not a deviation, but worth the line: `Card`'s padding on two boxes

`Card` supplies the 24px step §3.1 names, so the empty state on `/attendance`
(previously 32px) and the instructions box on `/membership-card` (previously
20px) now take the primitive's value. Neither of the two incumbent numbers is a
step the ladder names, which is the whole reason the container owns it.
