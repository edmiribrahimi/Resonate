## F-41.2-09-01 — The plan's "seven pairs" is wrong against the tree; check E carries NINE

**Severity:** informational, and it corrects a number three later plans would inherit.
**Disposition:** recorded. **Nothing was changed on account of it** — the gate is green
either way, and the figure is the gate's own.

The plan states its target three times — *"Check E now carries seven pairs"*, *"seven
files should now appear in both"*, *"equal in both directions with seven pairs in
each"*. **Measured on the base commit, before this plan's first edit, the pairing is
9 / 9**, and it is still 9 / 9 after.

```
          file(s) DECLARING the column clearance            : 9
          file(s) MOUNTING the responsive form              : 9
```

**Where the seven came from, and why it is not the tree's number.** Plan 41.2-07 ran in
its own worktree on base `64eb82e` and correctly reported **5 / 5 → 7 / 7**: the two
baseline files plus wave 1's three, plus its own two. But **two other plans in the same
wave each added one more** — 41.2-06 reported 6 / 6 from the same base, and 41.2-08
landed a ninth without printing the pairing at all. Three isolated worktrees, each
measuring a base the other two had not yet moved. **On the merged tree the four wave-3
surfaces are all present, and 5 + 4 = 9.**

**Why it is worth a finding rather than a silent correction.** A reconciliation told to
expect seven and finding nine has two readings available: *the plan is stale*, or *two
files declare a clearance nobody asked for*. The second is a **check-E failure
direction** — declaring without mounting — and it is the silent one. It was ruled out
by reading the gate's two sets rather than the count: both lists hold the **same nine
paths**, and both difference lists are empty. The nine are the two baseline files, wave
1's three, and wave 3's four, each accounted for by name.

**For every later plan in this phase:** the target at the end of the phase is 12 / 12.
Three surfaces remain, not five. **A plan's expected pairing figure is a number written
before the wave ran, and the wave's own worktrees cannot see each other** — so it is a
prediction, and the tree is the measurement.

## F-41.2-09-02 — The second instrument returned a VACUOUS ZERO on its first run, and it would have authorised twelve deletions

**Severity:** caught before any entry was touched; **zero entries were deleted in this
plan**, so nothing downstream inherited it.
**Disposition:** repaired, then a self-check added, then recorded — because the
near-miss is the whole point of the instrument existing.

The second instrument is required to be a raw needle count that **does not share the
gates' comment stripper**, because a round of this phase family measured that stripper
going blind inside a file while the gate printed *converted; remove this entry* and
exited 0. It was written as three chained `LC_ALL=C /usr/bin/grep` calls with a shell
variable standing in for the word-character class.

**On its first run it returned `overlay=0 native=0 sm:uses=0` on all eight files** —
including the four the gates report as live, carrying 3, 1, 1 and 3 overlays.

```
overlay=0   native=0   sm:uses=0    …/RedeemConfirmationModal.tsx     ← the gate says 3 and 4
overlay=0   native=0   sm:uses=0    …/SumUpCheckoutModal.tsx          ← the gate says 1 and 4
```

**The defect was in the instrument, not the tree.** The class was defined as
`W='[A-Za-z0-9_-]'` and then used as `[^$W]`, which expands to a bracket expression
nested inside a bracket expression and matches nothing intended. A plain
`grep -c 'fixed'` on the same file returned **3**, which is how the zero was caught: the
instrument disagreed with the crudest possible reading of the same file.

**Why this is the finding and not a footnote.** An instrument that returns zero on every
file is **indistinguishable from a tree with no debt left**. Had it been believed, the
rule this plan operates under — *delete an entry when the gate and a second instrument
both read zero* — would have authorised deleting **all twelve entries on both lists**,
in a wave whose stated expectation is zero deletions. That is not the debt-goes-quiet
shape; it is worse, because the counter would have fallen to zero and every row would
have carried a second instrument's agreement. **The four recorded mechanisms in this
phase family are a never-measured map, a fence match, an unguarded walk-membership check
and a comment stripper going blind. This is a fifth: a second instrument that measures
nothing and agrees with everything.**

**The repair, and the guard that outlives it.** The class is now `W='A-Za-z0-9_-'`, and
the instrument **refuses (exit 2) unless it first reproduces known answers on two
fixtures** — a positive fixture that must read 1/1/1 and a negative that must read
0/0/0. It prints `self-check PASSED` before any measurement, in every run quoted in the
SUMMARY.

```
self-check PASSED — positive fixture 1/1/1, negative fixture 0/0/0
```

**And the repaired instrument is independently corroborated:** its twelve figures are
**identical to the twelve plan 41.2-05 recorded** on a different base, file for file.
Two measurements a wave apart, agreeing without either having seen the other's numbers.

**Routed to plan 41.2-19**, which deletes entries on the strength of this instrument:
**a zero from it is only evidence if the run that produced it printed its self-check.**
A bare zero is a measurement that may not have happened.
