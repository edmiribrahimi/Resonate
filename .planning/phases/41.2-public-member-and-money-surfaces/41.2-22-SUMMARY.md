# Phase 41.2 Plan 22: the dialogs gate's exemptions become element-scoped — Summary

`verify-dialogs.mjs` forgave two whole FILES on a reason that named two of each
file's three overlays, so a third overlay written into either arrived pre-forgiven;
the four shells are now named one by one, with anchors the gate asserts on every run,
inside files check B opens and measures.

**Commit:** `0e68687`

---

## What moved

| | Before | After |
|---|---|---|
| mechanism | `NEVER_MEASURED_BY_B` — check B `continue`d on both paths | `EXEMPT_SHELLS` — four entries, one per shell |
| unit forgiven | the FILE | the SHELL |
| files check B opened | 255 | **257** |
| shells measured | 0 (never read) | **4**, all forgiven by name |
| a third overlay in either file | exit **0**, silently forgiven | exit **1**, named |
| a third overlay copying an exempt class string | exit **0** | exit **2**, refuses |
| `REMAINING` | 0 — because the files were skipped | 0 — **because the named shells are forgiven** |

That last row is the whole substance. The number did not move; what it means did.

---

## Requirements the correction had to satisfy

1. **Each entry names an element, with an anchor asserted present.** Shape
   `[path, anchor, shape, reason]`. An anchor matching zero shells **refuses** —
   that is what makes the list self-checking rather than declared.
2. **Each entry keeps its own reason, and the two files' reasons stay distinct.**
   `RedeemConfirmationModal.tsx` keeps the **one-directional** argument (the
   reverting row goes full-width under the thumb); `GuestTokenDisplay.tsx` keeps the
   **two-directional** one (the serve area *shrinks* to a panel body so the bartender
   must aim, while Cancel *grows*). Four reasons, not one cited four times.
3. **The files are still walked and their shells still measured.** Check B opens
   both, `shellShapes()` runs on both, and forgiveness is asked per shell.
4. **The report prints them** — path, line, shape, anchor, `applied N×` and the full
   reason — and the green now closes with what it took itself over.
5. **No threshold moved, no list widened, nothing else touched.** Every removed line
   in the diff was read: 41 deletions, all of them the two relocated exemptions, the
   superseded prose kept beside its correction, and three report lines replaced by
   more honest accounting.

## Proof, by asserted mutation

Every run below: mutate → `grep` proving the mutation landed with a non-zero count →
gate → revert → `git status --porcelain` / `git diff` empty → baseline reproduced.

**Each entry removed, one at a time — no entry is decoration:**

| Removed | Exit | Failures | At |
|---|---|---|---|
| Redeem acknowledgement | 1 | exactly 1 | `RedeemConfirmationModal.tsx:180` |
| Redeem serve screen | 1 | exactly 1 | `RedeemConfirmationModal.tsx:205` |
| menu acknowledgement | 1 | exactly 1 | `GuestTokenDisplay.tsx:257` |
| menu serve screen | 1 | exactly 1 | `GuestTokenDisplay.tsx:282` |

**The anchor made absent → the gate refuses**, rather than silently forgiving
nothing: **exit 2**, *"NO measured shell in that file carries it … the entry is
stale: it forgives nothing while looking like a guarded case."*

**The newcomer test — the deliverable:**

| File | Before (pre-fix gate) | After |
|---|---|---|
| `RedeemConfirmationModal.tsx` | exit **0**, `REMAINING = 0` | exit **1**, named at `:291` |
| `GuestTokenDisplay.tsx` | exit **0**, `REMAINING = 0` | exit **1**, named at `:670` |

The "before" column is a real run, not an inference: the pre-fix gate was
materialised from `HEAD` beside the current one, confirmed to be the old code by
grep (`EXEMPT_SHELLS` count 0), run against the probe, and deleted.

**And a route nobody had named, found and closed:** a third overlay written with the
*same class string* as an exempt shell does not inherit its forgiveness — the anchor
resolves twice and the gate **refuses, exit 2**, naming both lines.

**Instruments reproduce a known non-zero on a positive fixture and a known zero on a
negative one.** The gate itself is the instrument here, and it did: the removal
probes are the positive fixtures (each produced exactly one failure at a known line),
the unmodified runs are the negative one (exit 0, `REMAINING = 0`). A corroborating
signal came free — the gate's comment-hygiene counter moved `29706 → 29707` while a
probe was in the tree and back afterwards, which is a second reading of the same
mutation from a number nobody wired to it.

## What a green from this gate still does not mean

- **It does not say a dialog behaves.** Escape, the focus trap, the sheet rising from
  the bottom edge below 768 px and the page behind it not scrolling are **H41-2** — a
  person, at two widths — and still owed.
- **The four exempt shells are four dialogs without a focus trap.** They are declared
  correct *for their surface*, not correct *as dialogs*. Two of the controls inside
  them are under the 44 px floor **by decision** (touch-targets exemption 10), and
  RESP-03's criterion 5 is partly false because of it.
- **Nothing was verified by tests.** This repository has no test runner for the
  product (`CLAUDE.md` Guardrail 1). The evidence is the mutation runs above and
  `npm run build` exit 0.
- **`Lightbox.tsx` and the Phase 42 fence remain blind spots**, each for its own
  declared reason.
