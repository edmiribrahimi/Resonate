<objective>
Convert the ticket surface — one page, three domains.

Purpose: this surface holds the same secret as the public event page under a
**different predicate**, and the divergence is deliberate and documented in the
file at `:31-33`. On the event page a ticket holder sees the address only if the
night's reveal-on-purchase flag is set; here a ticket holder sees the night's free
venue text **always**. That is not a leak of the gated column — free text is
content somebody typed, and whoever typed an address into it published it — but it
**is a second, ungated door onto the same information**, and this phase is the
moment somebody is looking at that surface. `venue-secrecy.md` requires the exit
enumeration to be rebuilt by reading the code rather than carried forward, so this
plan rebuilds it and writes it down.

It also reaches the one exit that is on no enumeration: the wallet pass, which
writes a venue field onto a file that **leaves the product**, syncs to a device
and is recalled by nothing — the same irreversibility class as a sent reveal
email. That file carries zero class strings, so no plan opens it, which is exactly
why it is easy to leave off the list.

And it is the surface most likely to be argued into the narrow form: it already
writes the focus measure **by hand, twice**. It cannot have it. Check E forbids
the narrow form on any surface mounting a navigation, and D-41.2-01 mounts one on
all ten.

Output: one file converted, one enumeration completed in writing, and one owner
question raised rather than answered.
</objective>
