## 9. `FormatFilterRow` — the inversion, decided in writing

`41.2-PATTERNS.md` §6.3 names this file as one of the map's three declared gaps: the chip
primitive was copied **from** it (`src/components/ui/Chip.tsx:28-48`, in the primitive's own
docblock), and the 44px minimum occurs exactly twice tree-wide, both here. The direction is
inverted, so replacing the floor with the primitive is a judgement and not a copy, and the
plan required the reading be stated.

**The reading taken is the second: the floor declarations stay, and this file does not
adopt the primitive.** The reason is mechanical, not sentimental, and it is two facts in
the primitive's own source plus one trap:

1. **The primitive's only filled form is its selected state, and that fill is the
   interaction accent** — `Chip.tsx:62-69`, `CHIP_SELECTED = "border-accent bg-accent
   text-ground"`. Handing the current format chip to it puts the interaction hue on the
   **format channel**, which this file's docblock refuses in as many words: *"That accent
   is barred from the format channel: the moment one channel borrows the other, a format
   stops being identifiable."* And it is barred here **one element below** a tab row that
   owns that hue legitimately — which as of task 2 now renders it.
2. **The selected state is also what emits `aria-current`** (`Chip.tsx:178`). Declining the
   fill with `selected={false}` would silently drop the only non-colour channel the current
   chip has, which is `40-UI-SPEC.md` §10's whole subject.
3. **The remaining road** — an unselected chip with the ground and ink re-applied from the
   call site — is the **WR-05 trap** named at `PageShell.tsx:109-114`: same property, same
   specificity, so the emitted stylesheet's order decides rather than the class list.

**What the file DID take from the contract**, so that "stays" is not read as "untouched":
the legacy ground, ink and boundary aliases went onto the current tokens; the boundary is
`--control` rather than a line token, because a chip is a control and `Chip.tsx:41-44`
records the ratios that make the difference (**7.14 : 1** against **1.39 : 1**); and the
focus expression is now the one imported from the ladder, never re-spelled — this row had
**no declared focus indicator at all** before.
