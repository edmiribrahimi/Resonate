## Key Decisions

1. Singleton SDK pattern for `@sumup/sdk`
2. Cursor-based pagination with CursorEntry interface for back-navigation
3. Optional redirectUrl in createCheckout for backward compat
4. Google Pay config conditional on env var
5. Callback page polls 5x at 2s for webhook race condition
6. Refund button inside TransactionDetailInline (detail already loaded)
7. Scanner page split into server wrapper + ScannerClient for MobileNav
8. Member search uses getServiceClient() to bypass RLS
