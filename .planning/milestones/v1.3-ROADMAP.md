## Key Decisions

1. Motion library with LazyMotion + domAnimation (4.6kb) instead of full motion (34kb)
2. All motion components use `m` from `motion/react-m` for lightweight imports
3. MotionConfig `reducedMotion="user"` wraps entire app
4. PostHog EU instance with `flushAt: 1` for serverless reliability
5. Recharts for charts (BarChart, AreaChart, FunnelChart) — client components
6. CountUp with requestAnimationFrame + ease-out cubic + useReducedMotion
7. Guest list processing: 3 paths (existing user, new user, name-only)
8. Discount validation: ilike for case-insensitive, FOR UPDATE lock for atomic usage counting
9. CSV import later removed as unused feature; papaparse dependency cleaned up
10. ManagementSection restored without stats cards (tools-only)
