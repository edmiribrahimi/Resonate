## Key Decisions

1. html5-qrcode library for continuous camera-based QR scanning
2. ScanFlash component with CSS animations (no motion library dependency for scanner)
3. IndexedDB v2 schema with separate stores for tickets, memberships, and pending sync queue
4. @serwist/next for service worker integration with offline caching
5. Membership check-in reuses scanner UI — mode detection via QR prefix (ticket vs membership)
6. Undo check-in via dedicated `/api/tickets/checkin/undo` endpoint
7. Membership list API (`/api/membership/list`) for offline pre-caching of member data
8. Torch toggle uses mediaStreamTrack.applyConstraints({ advanced: [{ torch: true }] })
